## Orchestrator's correction, 2026-09-09: the one MISMATCH is a FALSE POSITIVE

**The real result is 74 of 74 unique DOIs correct. Nothing needs changing.**

The audit flagged `10.1530/EJE-20-0609` at `src/content/sexRationale.ts:185` as claiming pages
529-537 against CrossRef's 529-536. Line 185 is not a citation. It sits inside a comment block that
**documents the round-1 error and its fix**, quoting the old string as the historical record:

```
185:  *   "van Velzen DM et al. (2020), Eur J Endocrinol 183(5):529-537. DOI 10.1530/EJE-20-0609"
192:  * shipped 529-537. CrossRef (api.crossref.org/works/10.1530/EJE-20-0609) and PubMed
193:  * (PMID 33071222) independently give 529-536, so the round-1 string was off by one page.
198:  'van Velzen DM, et al. Eur J Endocrinol 183(5):529-536, 2020. DOI 10.1530/EJE-20-0609';
```

Line 198 is what ships, and it is `529-536`. Verified independently by the orchestrator against
`api.crossref.org/works/10.1530/EJE-20-0609`, which returns "Variation in sensitivity and rate of
change in body composition: steps toward individualizing transgender care", van Velzen, 2020,
European Journal of Endocrinology, page **529-536**. Logged in `REFERENCES.md`.

**The lesson for the next audit**, not a criticism of this one: a scanner that reads "the DOI and
the nearest metadata" cannot tell a live citation from a superseded one quoted inside a comment
that exists to record the correction. Any future run should treat a comment block as a claim only
when nothing else in the same module states the value.

  registry lookup, and it has not been done.
