# P2 Storage Engine (IndexedDB) Implementation Plan

> SUPERSEDED 2026-11-06 executed plan (P2 IndexedDB shipped). Current state `docs/STATUS.md`; decision AM-P2-1 in its decisions log.

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move persistence from the single localStorage document `fti.v3` to IndexedDB, one object store per record type plus a meta record (schemaVersion, revision), so that one bad record no longer refuses the whole document, a stale window can no longer overwrite newer data, the last tap survives a kill, and history no longer grows against a 5 MiB key, while the in-memory `AppState` and the Zustand store keep their shape.

**Architecture:** A pure record layer (`src/store/db/records.ts`, `assemble.ts`, `preserve.ts`) maps `AppState` to records, validates each record on read with the `AppStateSchema` field schema itself (invalid records are quarantined in place, listed and exportable), and keeps unknown keys and `.catch()`-repaired answers so a write never destroys them. A `RecordBackend` interface has two implementations: the browser one (`idb` 8.0.3 over IndexedDB database `fti`, BroadcastChannel `fti.revision`, the legacy `fti.v3` key read once) and an in-memory one for tests. The store keeps its synchronous actions; a subscription diffs each change by record identity and commits ONE readwrite transaction per action (one microtask, no debounce) against the revision this instance last read; a commit from a stale revision writes nothing and the instance re-reads. `main.tsx` reads the records before the first render, so intro and setup can never flash over stored data.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Zustand 5, Zod 4.5.4, `idb` 8.0.3 (already a dependency), `fake-indexeddb` 6.2.5 (already a devDependency; `npm view fake-indexeddb@6.2.5 version` returned `6.2.5` on 2026-11-04, latest 6.2.7; no install needed), Vitest 4 (jsdom), Playwright 1.63.0 (Chromium 1243, `iphone13` + `pixel7`).

**Spec:** `docs/plans/2026-11-04-aaa-rebuild-spec.md` (ruling R13; phase line P2). Audit IDs (B01..B18, D14, E03) refer to `docs/private/audit-2026-11-04/` (gitignored, this laptop only). P1 plan `docs/plans/2026-11-04-p0-p1-unblock.md` lands first; this plan is written against the post-P1 code its Tasks 6, 9, 10 and 17 describe.

## Amendments (lead rulings, 2026-11-04; binding, override task text)

- AM-P2-1 Rollback mirror. A pre-P2 build reads only `fti.v3`, so after P2 a rollback would load the stale first-import snapshot and look like data loss. P2 therefore keeps a best-effort mirror: on `visibilitychange` to hidden and on `pagehide`, the store writes the full serialised document to `fti.v3` (same JSON shape the export produces, so the old build's `parseState` loads it; optional fields it does not know are stripped). Never on the critical path, never per action; a quota error is swallowed and noted in the log only. The first-boot import still runs only when IndexedDB holds no records, so the mirror is never re-imported. Rejected: writing `fti.v3` on every commit (reintroduces the per-action whole-document cost P2 removes); no mirror (rollback = apparent data loss). Remove the mirror two releases after P2 ships (record in docs/STATUS.md).
- AM-P2-2 Document in docs/runbooks/deploy.md: a rollback past P2 shows data at most one app session old; rolling forward again does not re-import writes the old build made during the rollback window (export JSON from the old build and import it in the new one if that window matters).

```ts
// src/store/db/records.ts
//
// Spec R13: how the in-memory AppState maps onto IndexedDB records. Pure: no IndexedDB, no
// clock. One object store per AppState map field (key = that map's own key: a record id or a
// profile id), plus the `app` store holding the four singleton fields under their own names and
// the meta record (schemaVersion, revision). `schemaVersion` lives only in meta.
import type { AppState } from '../../domain/types';

/**
 * The records database (spec R13). The motivation clip keeps its own database, `fti-assets`
 * (src/domain/motivation/assets.ts): see src/store/db/idb.ts for why there are two.
 */
export const RECORD_DB_NAME = 'fti';

/** The AppState fields stored one entry per record, in a store named after the field. */
export const MAP_STORES = [
  'profiles',
  'availability',
  'plans',
  'cursors',
  'pauses',
  'assignments',
  'sets',
  'bodyMass',
  'hydration',
  'intake',
  'weeklyReviews',
  'reminderSettings',
  'motivation',
  'specimens',
  'capsules',
  'customExercises',
  'notes',
] as const satisfies readonly (keyof AppState)[];
export type MapStore = (typeof MAP_STORES)[number];

/** The AppState fields stored as one record each in the `app` store, keyed by field name. */
export const SINGLETON_KEYS = ['activeProfileId', 'pushDevice', 'setupDraft', 'ui'] as const satisfies readonly (keyof AppState)[];
export type SingletonKey = (typeof SINGLETON_KEYS)[number];

export const APP_STORE = 'app';
/** The meta record's key in the `app` store. */
export const META_KEY = 'meta';
export type StoreName = MapStore | typeof APP_STORE;
export const ALL_STORES: readonly StoreName[] = [...MAP_STORES, APP_STORE];

/*
 * Compile-time exhaustiveness (rule 2): every AppState field is a map store, a singleton, or
 * schemaVersion (meta). A field added to AppState and to neither list fails to compile here
 * instead of silently never being stored.
 */
type Unstored = Exclude<keyof AppState, MapStore | SingletonKey | 'schemaVersion'>;
const EVERY_FIELD_IS_STORED: [Unstored] extends [never] ? true : never = true;
void EVERY_FIELD_IS_STORED;

/** Map stores whose keys are profile ids (the root refinement's PROFILE_KEYED_MAPS). */
export const PROFILE_KEYED_STORES: readonly MapStore[] = MAP_STORES.filter(
  (s) => s !== 'profiles' && s !== 'plans' && s !== 'sets',
);

/**
 * Map stores whose record is a per-profile LIST. Each list item is validated on its own on read
 * (one bad row is quarantined, its neighbours load), and the property named here identifies an
 * item across a rewrite, so unknown keys read with it go back onto the same item (audit B06).
 */
export const LIST_ITEM_ID = {
  pauses: 'id',
  assignments: 'date',
  bodyMass: 'id',
  hydration: 'date',
  intake: 'date',
  weeklyReviews: 'weekStart',
  customExercises: 'id',
} as const satisfies Partial<Record<MapStore, string>>;
export type ListStore = keyof typeof LIST_ITEM_ID;

export function isListStore(store: StoreName): store is ListStore {
  return Object.hasOwn(LIST_ITEM_ID, store);
}

/** One stored record. `value` is what goes to IndexedDB (structured-clonable JSON). */
export interface RecordPut {
  store: StoreName;
  key: string;
  value: unknown;
}
export interface RecordDelete {
  store: StoreName;
  key: string;
}
/** What one commit writes. `clear: true` empties every store except meta first (wipe, replace). */
export interface RecordOps {
  clear: boolean;
  puts: RecordPut[];
  deletes: RecordDelete[];
}

export const NO_OPS: RecordOps = { clear: false, puts: [], deletes: [] };

export function isEmptyOps(ops: RecordOps): boolean {
  return !ops.clear && ops.puts.length === 0 && ops.deletes.length === 0;
}

/** Every record of a document, for a full replace (import) or a test seed. */
export function splitState(state: AppState): RecordPut[] {
  const puts: RecordPut[] = [];
  for (const store of MAP_STORES) {
    for (const [key, value] of Object.entries(state[store])) puts.push({ store, key, value });
  }
  for (const key of SINGLETON_KEYS) puts.push({ store: APP_STORE, key, value: state[key] });
  return puts;
}

/**
 * The records whose identity changed between two documents (spec R13: per-action writes of the
 * records whose identity changed). Actions replace what they touch and keep everything else by
 * reference, so identity is the change signal, exactly as the store's old persistedChanged was.
 */
export function diffStates(prev: AppState, next: AppState): RecordOps {
  const puts: RecordPut[] = [];
  const deletes: RecordDelete[] = [];
  for (const store of MAP_STORES) {
    const a: Record<string, unknown> = prev[store];
    const b: Record<string, unknown> = next[store];
    if (a === b) continue;
    for (const [key, value] of Object.entries(b)) {
      if (!Object.hasOwn(a, key) || a[key] !== value) puts.push({ store, key, value });
    }
    for (const key of Object.keys(a)) {
      if (!Object.hasOwn(b, key)) deletes.push({ store, key });
    }
  }
  for (const key of SINGLETON_KEYS) {
    if (prev[key] !== next[key]) puts.push({ store: APP_STORE, key, value: next[key] });
  }
  return { clear: false, puts, deletes };
}

/**
 * Two batches as one: later puts and deletes of the same record win. A `clear` in `later`
 * discards everything `earlier` held (it is about to be erased anyway).
 */
export function mergeOps(earlier: RecordOps, later: RecordOps): RecordOps {
  if (later.clear) return later;
  const byRecord = new Map<string, { put: RecordPut } | { del: RecordDelete }>();
  const id = (r: { store: string; key: string }): string => `${r.store}\u0000${r.key}`;
  for (const p of earlier.puts) byRecord.set(id(p), { put: p });
  for (const d of earlier.deletes) byRecord.set(id(d), { del: d });
  for (const p of later.puts) byRecord.set(id(p), { put: p });
  for (const d of later.deletes) byRecord.set(id(d), { del: d });
  const puts: RecordPut[] = [];
  const deletes: RecordDelete[] = [];
  for (const entry of byRecord.values()) {
    if ('put' in entry) puts.push(entry.put);
    else deletes.push(entry.del);
  }
  return { clear: earlier.clear, puts, deletes };
}

function isPlainObject(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v);
}

/** The `app` store key an unknown top-level field of an imported fti.v3 document is kept under. */
export function legacyExtraKey(field: string): string {
  return `legacy:${field}`;
}

/**
 * An UNVALIDATED (already migrated) fti.v3 document as raw records, for the first-boot import
 * (spec R13). Nothing is parsed here: assembleState validates what is read back, so an imported
 * record and a record written later go through one validator. A top-level field this build does
 * not know is kept in the `app` store under legacyExtraKey() (audit B06). Returns an error when
 * a map field is not an object, because there is then no record to split it into.
 */
export function splitDocument(doc: Record<string, unknown>): { ok: true; puts: RecordPut[] } | { ok: false; error: string } {
  const puts: RecordPut[] = [];
  const known = new Set<string>([...MAP_STORES, ...SINGLETON_KEYS, 'schemaVersion']);
  for (const store of MAP_STORES) {
    const field = doc[store];
    if (field === undefined) continue;
    if (!isPlainObject(field)) return { ok: false, error: `${store}: expected an object` };
    for (const [key, value] of Object.entries(field)) puts.push({ store, key, value });
  }
  for (const key of SINGLETON_KEYS) {
    if (doc[key] !== undefined) puts.push({ store: APP_STORE, key, value: doc[key] });
  }
  for (const [field, value] of Object.entries(doc)) {
    if (!known.has(field)) puts.push({ store: APP_STORE, key: legacyExtraKey(field), value });
  }
  return { ok: true, puts };
}

/** Records grouped by store then key, the shape a full read returns. */
export function groupRecords(puts: readonly RecordPut[]): Map<StoreName, Map<string, unknown>> {
  const out = new Map<StoreName, Map<string, unknown>>();
  for (const { store, key, value } of puts) {
    let map = out.get(store);
    if (map === undefined) {
      map = new Map<string, unknown>();
      out.set(store, map);
    }
    map.set(key, value);
  }
  return out;
}
```

```ts
// src/store/db/preserve.ts
//
// What this build reads but does not understand, kept so a write never destroys it.
//   Audit B06: keys a newer build added (z.object strips them on read) go back onto the same
//   record, and the same list item, when this build rewrites it.
//   Audit B10: a `.catch()` repair (an unreadable sex read as 'nd', an unknown equipment tier as
//   'full-gym', an out-of-range PAL as null) is listed, and the STORED answer is written back
//   unless the user has since changed that field.
//   Quarantined list items stay in their list on disk, after the readable items.
// Pure: no IndexedDB.
import type { z } from 'zod';
import { ActivityPalStrictSchema, ProfileEquipmentStrictSchema, SexEnumSchema } from '../../domain/schema';
import { LIST_ITEM_ID, isListStore, type RecordOps, type StoreName } from './records';

/** Unknown keys of one stored object: its own, and those of its nested plain objects. */
export interface Extras {
  own: Record<string, unknown>;
  nested: Record<string, Extras>;
}

/** A stored answer a `.catch()` replaced on read (audit B10). */
export interface Repair {
  store: 'profiles';
  key: string;
  path: readonly string[];
  /** The value as stored. */
  stored: unknown;
  /** The value the app runs with. */
  readAs: unknown;
}

export interface Preserved {
  /** By recordId() or itemRecordId(). */
  extras: ReadonlyMap<string, Extras>;
  repairs: readonly Repair[];
  /** By recordId(): the raw list items that failed validation, kept on disk in place. */
  quarantinedItems: ReadonlyMap<string, readonly unknown[]>;
}

export const EMPTY_PRESERVED: Preserved = { extras: new Map(), repairs: [], quarantinedItems: new Map() };

export function recordId(store: StoreName, key: string): string {
  return `${store}\u0000${key}`;
}

export function itemRecordId(store: StoreName, key: string, itemId: string): string {
  return `${store}\u0000${key}\u0000${itemId}`;
}

/**
 * The profile fields whose schema repairs a bad value with `.catch()`, each with the same schema
 * minus the catch. A stored value the strict schema refuses is a repair.
 */
const REPAIRABLE: readonly { path: readonly string[]; strict: z.ZodType }[] = [
  { path: ['body', 'sex'], strict: SexEnumSchema },
  { path: ['equipment'], strict: ProfileEquipmentStrictSchema },
  { path: ['activityPal'], strict: ActivityPalStrictSchema },
];

function isPlainObject(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v);
}

/** The keys of `raw` that `parsed` lacks, recursively through plain objects (not arrays). */
export function extrasOf(raw: unknown, parsed: unknown): Extras | null {
  if (!isPlainObject(raw) || !isPlainObject(parsed)) return null;
  const own: Record<string, unknown> = {};
  const nested: Record<string, Extras> = {};
  for (const [key, value] of Object.entries(raw)) {
    if (!Object.hasOwn(parsed, key)) {
      own[key] = value;
      continue;
    }
    const sub = extrasOf(value, parsed[key]);
    if (sub !== null) nested[key] = sub;
  }
  return Object.keys(own).length === 0 && Object.keys(nested).length === 0 ? null : { own, nested };
}

/** `value` with the unknown keys put back where their parent object still exists. */
export function withExtras(value: unknown, extras: Extras | undefined): unknown {
  if (extras === undefined || !isPlainObject(value)) return value;
  const out: Record<string, unknown> = { ...value };
  for (const [key, v] of Object.entries(extras.own)) {
    if (!Object.hasOwn(out, key)) out[key] = v;
  }
  for (const [key, sub] of Object.entries(extras.nested)) {
    if (Object.hasOwn(out, key)) out[key] = withExtras(out[key], sub);
  }
  return out;
}

function getPath(v: unknown, path: readonly string[]): unknown {
  let at: unknown = v;
  for (const key of path) {
    if (!isPlainObject(at)) return undefined;
    at = at[key];
  }
  return at;
}

function setPath(v: unknown, path: readonly string[], leaf: unknown): unknown {
  const [head, ...rest] = path;
  if (head === undefined || !isPlainObject(v)) return v;
  return { ...v, [head]: rest.length === 0 ? leaf : setPath(v[head], rest, leaf) };
}

export function captureExtras(into: Map<string, Extras>, id: string, raw: unknown, parsed: unknown): void {
  const found = extrasOf(raw, parsed);
  if (found !== null) into.set(id, found);
}

export function captureRepairs(into: Repair[], key: string, raw: unknown, parsed: unknown): void {
  for (const { path, strict } of REPAIRABLE) {
    const stored = getPath(raw, path);
    if (stored === undefined || strict.safeParse(stored).success) continue;
    into.push({ store: 'profiles', key, path, stored, readAs: getPath(parsed, path) });
  }
}

export function listItemId(store: keyof typeof LIST_ITEM_ID, item: unknown): string {
  const id: unknown = isPlainObject(item) ? item[LIST_ITEM_ID[store]] : undefined;
  return typeof id === 'string' ? id : '';
}

/** The value to store for one record: the app's value plus everything preserved for it. */
export function encodeValue(store: StoreName, key: string, value: unknown, preserved: Preserved): unknown {
  if (isListStore(store) && Array.isArray(value)) {
    const items = value.map((item: unknown) =>
      withExtras(item, preserved.extras.get(itemRecordId(store, key, listItemId(store, item)))),
    );
    return [...items, ...(preserved.quarantinedItems.get(recordId(store, key)) ?? [])];
  }
  let out = withExtras(value, preserved.extras.get(recordId(store, key)));
  if (store === 'profiles') {
    for (const repair of preserved.repairs) {
      if (repair.key !== key) continue;
      // Only while the app still holds the substitute: a value the user chose since wins.
      if (getPath(out, repair.path) === repair.readAs) out = setPath(out, repair.path, repair.stored);
    }
  }
  return out;
}

export function encodeOps(ops: RecordOps, preserved: Preserved): RecordOps {
  return {
    clear: ops.clear,
    puts: ops.puts.map((p) => ({ ...p, value: encodeValue(p.store, p.key, p.value, preserved) })),
    deletes: ops.deletes,
  };
}
```

```ts
// src/store/db/assemble.ts
//
// Spec R13 / audit B01, B04: the stored records become one AppState, validated RECORD BY RECORD.
// An invalid record is quarantined (left exactly as stored, listed to the user, exportable)
// instead of refusing the whole document. Every per-record schema is the AppStateSchema field
// schema itself, applied to a one-entry map, so the record rules cannot drift from the document
// rules (AGENTS.md rule 2). Pure: no IndexedDB.
import { AppStateSchema, CURRENT_SCHEMA_VERSION, defaultState } from '../../domain/schema';
import type { AppState } from '../../domain/types';
import {
  captureExtras,
  captureRepairs,
  itemRecordId,
  listItemId,
  recordId,
  type Extras,
  type Preserved,
  type Repair,
} from './preserve';
import {
  APP_STORE,
  MAP_STORES,
  PROFILE_KEYED_STORES,
  isListStore,
  type MapStore,
  type StoreName,
} from './records';

/** Every stored record by store, then by key. A store with no records may be absent. */
export type StoredRecords = ReadonlyMap<StoreName, ReadonlyMap<string, unknown>>;

/** One stored record (or one item of a per-profile list) this build could not read. */
export interface QuarantinedRecord {
  store: StoreName;
  key: string;
  /** Position in the stored per-profile list, or null for a whole record. */
  index: number | null;
  /** The first validation issue, path then reason, as parseState words it. */
  reason: string;
  /** The record exactly as stored. */
  raw: unknown;
}

export type AssembleResult =
  | {
      ok: true;
      state: AppState;
      quarantine: readonly QuarantinedRecord[];
      repairs: readonly Repair[];
      preserved: Preserved;
    }
  | { ok: false; error: string };

const FIELD = AppStateSchema.shape;

type Parsed = { ok: true; value: unknown } | { ok: false; reason: string };

function reasonOf(issues: readonly { path: readonly PropertyKey[]; message: string }[], prefix: string): string {
  const first = issues[0];
  if (first === undefined) return `${prefix}: unknown validation failure`;
  const where = [prefix, ...first.path.map(String)].join('.');
  return `${where}: ${first.message}`;
}

/** One record of a map store, through that field's own schema on a one-entry map. */
function parseEntry(store: MapStore, key: string, value: unknown): Parsed {
  const result = FIELD[store].safeParse({ [key]: value });
  if (!result.success) return { ok: false, reason: reasonOf(result.error.issues, store) };
  const data: Record<string, unknown> = result.data;
  return { ok: true, value: data[key] };
}

/**
 * Assembles the document. Refuses as a whole only when a PROFILE record is invalid: every other
 * record type hangs off a profile, so quarantining a profile would orphan its whole history and
 * open first-run setup over it (audit B01); the recovery screen is the honest answer there.
 */
export function assembleState(stored: StoredRecords): AssembleResult {
  const quarantine: QuarantinedRecord[] = [];
  const extras = new Map<string, Extras>();
  const repairs: Repair[] = [];
  const quarantinedItems = new Map<string, unknown[]>();
  const records = (store: StoreName): ReadonlyMap<string, unknown> => stored.get(store) ?? new Map<string, unknown>();
  const out: Record<string, Record<string, unknown>> = {};

  // Profiles first: every other map is checked against their ids.
  const profiles: Record<string, unknown> = {};
  for (const [key, raw] of records('profiles')) {
    const parsed = parseEntry('profiles', key, raw);
    if (!parsed.ok) return { ok: false, error: `profiles.${key}: ${parsed.reason}` };
    const id: unknown = Reflect.get(parsed.value as object, 'id');
    if (id !== key) return { ok: false, error: `profiles.${key}: profile record key "${key}" does not match its id "${String(id)}"` };
    profiles[key] = parsed.value;
    captureExtras(extras, recordId('profiles', key), raw, parsed.value);
    captureRepairs(repairs, key, raw, parsed.value);
  }
  out.profiles = profiles;
  const profileIds = new Set(Object.keys(profiles));

  for (const store of MAP_STORES) {
    if (store === 'profiles') continue;
    const map: Record<string, unknown> = {};
    for (const [key, raw] of records(store)) {
      if (PROFILE_KEYED_STORES.includes(store) && !profileIds.has(key)) {
        quarantine.push({
          store,
          key,
          index: null,
          reason: `${store}.${key}: ${store} is keyed by profile id, and "${key}" is not a known profile`,
          raw,
        });
        continue;
      }
      if (isListStore(store)) {
        if (!Array.isArray(raw)) {
          quarantine.push({ store, key, index: null, reason: `${store}.${key}: expected a list`, raw });
          continue;
        }
        const items: unknown[] = [];
        raw.forEach((item: unknown, index) => {
          const parsed = parseEntry(store, key, [item]);
          if (!parsed.ok) {
            quarantine.push({ store, key, index, reason: parsed.reason.replace(`${store}.${key}.0`, `${store}.${key}.${String(index)}`), raw: item });
            quarantinedItems.set(recordId(store, key), [...(quarantinedItems.get(recordId(store, key)) ?? []), item]);
            return;
          }
          const value = (parsed.value as unknown[])[0];
          items.push(value);
          captureExtras(extras, itemRecordId(store, key, listItemId(store, value)), item, value);
        });
        map[key] = items;
        continue;
      }
      const parsed = parseEntry(store, key, raw);
      if (!parsed.ok) {
        quarantine.push({ store, key, index: null, reason: parsed.reason, raw });
        continue;
      }
      if (store === 'sets' && Reflect.get(parsed.value as object, 'id') !== key) {
        quarantine.push({ store, key, index: null, reason: `sets.${key}: set record key "${key}" does not match its id`, raw });
        continue;
      }
      map[key] = parsed.value;
      captureExtras(extras, recordId(store, key), raw, parsed.value);
    }
    out[store] = map;
  }

  const app = records(APP_STORE);
  const fallback = defaultState();
  const hasProfiles = profileIds.size > 0;

  let activeProfileId: string | null = null;
  const rawActive = app.get('activeProfileId');
  const active = FIELD.activeProfileId.safeParse(rawActive ?? null);
  if (active.success && (active.data === null || profileIds.has(active.data))) {
    activeProfileId = active.data;
  } else {
    quarantine.push({ store: APP_STORE, key: 'activeProfileId', index: null, reason: 'activeProfileId: not a known profile', raw: rawActive });
  }
  // A document with profiles always has an active one: null would open first-run setup over them.
  if (activeProfileId === null && hasProfiles) activeProfileId = [...profileIds].sort()[0] ?? null;

  const rawDevice = app.get('pushDevice');
  const device = FIELD.pushDevice.safeParse(rawDevice ?? null);
  if (!device.success) {
    quarantine.push({ store: APP_STORE, key: 'pushDevice', index: null, reason: reasonOf(device.error.issues, 'pushDevice'), raw: rawDevice });
  } else {
    captureExtras(extras, recordId(APP_STORE, 'pushDevice'), rawDevice, device.data);
  }

  const rawDraft = app.get('setupDraft');
  // SetupDraftSchema catches to null: a corrupt draft costs the draft, never the document.
  const draft = FIELD.setupDraft.parse(rawDraft ?? null);

  const rawUi = app.get('ui');
  let ui = fallback.ui;
  if (rawUi !== undefined) {
    const parsedUi = FIELD.ui.safeParse(rawUi);
    if (parsedUi.success) {
      ui = parsedUi.data;
      captureExtras(extras, recordId(APP_STORE, 'ui'), rawUi, parsedUi.data);
    } else {
      quarantine.push({ store: APP_STORE, key: 'ui', index: null, reason: reasonOf(parsedUi.error.issues, 'ui'), raw: rawUi });
      // Preferences only. A user with profiles has met the intro and the boot already.
      ui = { ...fallback.ui, introSeen: hasProfiles, bootSeen: hasProfiles };
    }
  }

  // Every field below was produced by its own AppStateSchema field schema above.
  const state = {
    schemaVersion: CURRENT_SCHEMA_VERSION,
    activeProfileId,
    ...out,
    pushDevice: device.success ? device.data : null,
    setupDraft: draft,
    ui,
  } as AppState;
  return {
    ok: true,
    state,
    quarantine,
    repairs,
    preserved: { extras, repairs, quarantinedItems },
  };
}
```

```ts
// src/store/db/backend.ts
//
// Spec R13: what the store needs from storage, as one interface with two implementations: the
// browser's (IndexedDB + BroadcastChannel + the legacy fti.v3 key, src/store/persistence.ts) and
// an in-memory one for tests (./memoryBackend.ts), so no unit test needs IndexedDB or Web Storage.
import type { StoredRecords } from './assemble';
import type { RecordOps } from './records';

/** The meta record in the `app` store. Absent on a database nothing has written yet. */
export interface MetaRecord {
  /** The AppState schema version the records were written under (CURRENT_SCHEMA_VERSION). */
  schemaVersion: number;
  /** [commits] Increments by one per committed transaction; 0 = nothing written yet. */
  revision: number;
}

export type ReadResult =
  | { ok: true; meta: MetaRecord | null; records: StoredRecords }
  | { ok: false; reason: 'unavailable'; error: string };

export type CommitResult =
  | { ok: true; revision: number }
  /** Another instance committed first: nothing was written; `revision` is the stored one. */
  | { ok: false; reason: 'stale'; revision: number }
  /** 'serialize': a value IndexedDB cannot clone (DataCloneError); retrying the same value fails. */
  | { ok: false; reason: 'quota' | 'unavailable' | 'serialize'; error: string };

/** The record half: one read of everything, one readwrite transaction per commit. */
export interface RecordStore {
  read(): Promise<ReadResult>;
  /**
   * Applies `ops` in ONE readwrite transaction and bumps the revision, or writes nothing.
   * Refused as 'stale' unless the stored revision equals `baseRevision` (absent meta = 0).
   * `schemaVersion` is stamped into meta.
   */
  commit(ops: RecordOps, baseRevision: number, schemaVersion: number): Promise<CommitResult>;
}

export interface RecordBackend extends RecordStore {
  /** Tells every other instance of the app that `revision` was committed. */
  announce(revision: number): void;
  /** Called with each revision another instance announces. Returns the unsubscribe. */
  onAnnounce(listener: (revision: number) => void): () => void;
  /** The pre-R13 document text under fti.v3, or null. Read once, at first boot. */
  readLegacy(): string | null;
  /** Removes fti.v3. Called by the wipe only: the import leaves it as a fallback (rule 7). */
  removeLegacy(): void;
}
```

```ts
// src/store/db/errors.ts
//
// How a storage failure is classified, shared by the Web Storage and IndexedDB paths (rule 2).

/**
 * A quota failure must never be swallowed (finding H3 / A42). Browsers disagree on how they
 * report it, so check the standard name, the Firefox legacy name, and both legacy DOMException
 * codes. Structural rather than `instanceof DOMException`: a thrown value can come from another
 * realm, and the legacy Safari form is not a DOMException at all.
 */
export function isQuotaExceeded(e: unknown): boolean {
  if (typeof e !== 'object' || e === null) return false;
  const name: unknown = Reflect.get(e, 'name');
  const code: unknown = Reflect.get(e, 'code');
  return (
    name === 'QuotaExceededError' ||
    name === 'NS_ERROR_DOM_QUOTA_REACHED' ||
    code === 22 || // DOMException.QUOTA_EXCEEDED_ERR
    code === 1014 // Firefox NS_ERROR_DOM_QUOTA_REACHED
  );
}

/** The thrown value's message, read structurally (jsdom's DOMException is not this realm's Error). */
export function messageOf(e: unknown): string {
  if (typeof e === 'object' && e !== null) {
    const message: unknown = Reflect.get(e, 'message');
    if (typeof message === 'string' && message.length > 0) return message;
  }
  return String(e);
}
```

```ts
// src/store/db/idb.ts
//
// Spec R13: the IndexedDB half of the storage engine. One database (RECORD_DB_NAME), one object
// store per AppState map field plus `app` (singletons + meta), out-of-line string keys. The only
// app module besides src/domain/motivation/assets.ts that may open IndexedDB (eslint.config.js).
//
// Why two databases (records here, the motivation clip in `fti-assets`): merging would copy
// clips of up to 150 MiB between databases on upgrade and tie the clip module's version to this
// engine's; no transaction ever spans a record and the clip (resolveVideoSrc falls back when the
// clip is gone). The wipe clears this database first, then the clip (src/ui/settings/DataSection.tsx).
import { openDB, type IDBPDatabase } from 'idb';
import type { StoredRecords } from './assemble';
import type { CommitResult, MetaRecord, ReadResult, RecordStore } from './backend';
import { isQuotaExceeded, messageOf } from './errors';
import { ALL_STORES, APP_STORE, META_KEY, RECORD_DB_NAME, type RecordOps, type StoreName } from './records';


let connection: Promise<IDBPDatabase> | null = null;

/**
 * Opens the database at WHATEVER version it already has, and upgrades (version + 1) only when a
 * store this build needs is missing. A fixed version would make an older build fail to open a
 * database a newer build had upgraded (audit B06, rollback); stores a newer build added are left
 * alone. A rejected open is evicted from the cache: IndexedDB failures are not permanent.
 */
function open(name: string): Promise<IDBPDatabase> {
  connection ??= (async () => {
    let db = await openDB(name);
    const missing = ALL_STORES.filter((s) => !db.objectStoreNames.contains(s));
    if (missing.length === 0) return watch(db);
    const version = db.version + 1;
    db.close();
    db = await openDB(name, version, {
      upgrade(upgrading) {
        for (const store of ALL_STORES) {
          if (!upgrading.objectStoreNames.contains(store)) upgrading.createObjectStore(store);
        }
      },
    });
    return watch(db);
  })().catch((error: unknown) => {
    connection = null;
    throw error;
  });
  return connection;
}

/** A newer build asking to upgrade gets the database: this connection closes and is forgotten. */
function watch(db: IDBPDatabase): IDBPDatabase {
  db.addEventListener('versionchange', () => {
    db.close();
    connection = null;
  });
  return db;
}

/** Drops the cached connection (tests swap globalThis.indexedDB between cases). */
export function resetRecordDbForTests(): void {
  connection = null;
}

function revisionOf(meta: unknown): number {
  const revision: unknown = typeof meta === 'object' && meta !== null ? Reflect.get(meta, 'revision') : undefined;
  return typeof revision === 'number' && Number.isInteger(revision) && revision >= 0 ? revision : 0;
}

function metaOf(raw: unknown): MetaRecord | null {
  if (typeof raw !== 'object' || raw === null) return null;
  const schemaVersion: unknown = Reflect.get(raw, 'schemaVersion');
  return {
    schemaVersion: typeof schemaVersion === 'number' ? schemaVersion : 0,
    revision: revisionOf(raw),
  };
}

function failureOf(e: unknown): 'quota' | 'unavailable' | 'serialize' {
  if (isQuotaExceeded(e)) return 'quota';
  const name: unknown = typeof e === 'object' && e !== null ? Reflect.get(e, 'name') : undefined;
  return name === 'DataCloneError' ? 'serialize' : 'unavailable';
}

export function idbRecordStore(name: string = RECORD_DB_NAME): RecordStore {
  return {
    async read(): Promise<ReadResult> {
      try {
        const db = await open(name);
        const tx = db.transaction([...ALL_STORES], 'readonly');
        const records = new Map<StoreName, Map<string, unknown>>();
        let meta: MetaRecord | null = null;
        await Promise.all(
          ALL_STORES.map(async (store) => {
            const os = tx.objectStore(store);
            const [keys, values] = await Promise.all([os.getAllKeys(), os.getAll()]);
            const map = new Map<string, unknown>();
            keys.forEach((key, i) => {
              if (store === APP_STORE && key === META_KEY) meta = metaOf(values[i]);
              else if (typeof key === 'string') map.set(key, values[i]);
            });
            records.set(store, map);
          }),
        );
        await tx.done;
        const stored: StoredRecords = records;
        return { ok: true, meta, records: stored };
      } catch (e) {
        return { ok: false, reason: 'unavailable', error: messageOf(e) };
      }
    },

    async commit(ops: RecordOps, baseRevision: number, schemaVersion: number): Promise<CommitResult> {
      let db: IDBPDatabase;
      try {
        db = await open(name);
      } catch (e) {
        return { ok: false, reason: failureOf(e), error: messageOf(e) };
      }
      const touched = new Set<StoreName>([APP_STORE]);
      if (ops.clear) for (const s of ALL_STORES) touched.add(s);
      for (const p of ops.puts) touched.add(p.store);
      for (const d of ops.deletes) touched.add(d.store);
      const tx = db.transaction([...touched], 'readwrite');
      try {
        const app = tx.objectStore(APP_STORE);
        const current: unknown = await app.get(META_KEY);
        const stored = revisionOf(current);
        if (stored !== baseRevision) {
          tx.abort();
          await tx.done.catch(() => undefined);
          return { ok: false, reason: 'stale', revision: stored };
        }
        // Every request below is issued in this same turn, so the transaction never idles.
        const requests: Promise<unknown>[] = [];
        if (ops.clear) for (const s of ALL_STORES) requests.push(tx.objectStore(s).clear());
        for (const p of ops.puts) requests.push(tx.objectStore(p.store).put(p.value, p.key));
        for (const d of ops.deletes) requests.push(tx.objectStore(d.store).delete(d.key));
        const revision = baseRevision + 1;
        const meta: MetaRecord = { schemaVersion, revision };
        requests.push(app.put({ ...(typeof current === 'object' && current !== null ? current : {}), ...meta }, META_KEY));
        await Promise.all([...requests, tx.done]);
        return { ok: true, revision };
      } catch (e) {
        await tx.done.catch(() => undefined);
        const error: unknown = tx.error ?? e;
        return { ok: false, reason: failureOf(error), error: messageOf(error) };
      }
    },
  };
}
```

```ts
// src/store/db/channel.ts
//
// Audit B03 / spec R13: every instance of the app on this origin (tabs, the installed app beside
// a browser tab) hears each committed revision, so a stale instance reloads its records instead
// of writing over newer ones. BroadcastChannel never delivers to the sender. Where it does not
// exist, nothing is announced; the revision check inside every commit still refuses a stale
// write (src/store/db/idb.ts).

export const REVISION_CHANNEL_NAME = 'fti.revision';

export interface RevisionChannel {
  announce(revision: number): void;
  subscribe(listener: (revision: number) => void): () => void;
}

function revisionIn(data: unknown): number | null {
  const revision: unknown = typeof data === 'object' && data !== null ? Reflect.get(data, 'revision') : undefined;
  return typeof revision === 'number' && Number.isInteger(revision) && revision >= 0 ? revision : null;
}

export function broadcastRevisionChannel(name: string = REVISION_CHANNEL_NAME): RevisionChannel {
  if (typeof BroadcastChannel === 'undefined') {
    return { announce: () => undefined, subscribe: () => () => undefined };
  }
  // Opened on first use: a backend that only reads (recovery export, tests) holds no channel.
  let channel: BroadcastChannel | null = null;
  const open = (): BroadcastChannel => (channel ??= new BroadcastChannel(name));
  return {
    announce(revision: number): void {
      open().postMessage({ revision });
    },
    subscribe(listener: (revision: number) => void): () => void {
      const channel = open();
      const handler = (e: MessageEvent): void => {
        const revision = revisionIn(e.data);
        if (revision !== null) listener(revision);
      };
      channel.addEventListener('message', handler);
      return () => {
        channel.removeEventListener('message', handler);
      };
    },
  };
}
```

```ts
// src/store/db/memoryBackend.ts
//
// The storage engine's test double (spec R13): the same contract as the browser backend, kept in
// a plain object. Two backends built on one MemoryDisk are two instances of the app on one
// origin. No IndexedDB and no Web Storage, so the existing suites need neither.
import type { CommitResult, MetaRecord, ReadResult, RecordBackend } from './backend';
import { ALL_STORES, APP_STORE, type RecordOps, type StoreName } from './records';

export interface MemoryDisk {
  records: Map<StoreName, Map<string, unknown>>;
  meta: MetaRecord | null;
  legacy: string | null;
  /** Every announce, to every backend on this disk except the sender. */
  listeners: Set<{ from: object; listener: (revision: number) => void }>;
}

export function createMemoryDisk(opts: { legacy?: string | null } = {}): MemoryDisk {
  return { records: new Map(), meta: null, legacy: opts.legacy ?? null, listeners: new Set() };
}

export interface MemoryBackend extends RecordBackend {
  disk: MemoryDisk;
  /** Every batch this backend committed, in order (after encoding). */
  commits: RecordOps[];
  /** The next commit fails with this reason instead of writing. */
  failNextCommit(reason: 'quota' | 'unavailable' | 'serialize'): void;
  /** Every read fails as unavailable (a blocked IndexedDB). */
  makeUnavailable(): void;
}

export function createMemoryBackend(opts: { disk?: MemoryDisk; legacy?: string | null } = {}): MemoryBackend {
  const disk = opts.disk ?? createMemoryDisk({ legacy: opts.legacy ?? null });
  const self = {};
  let failNext: 'quota' | 'unavailable' | 'serialize' | null = null;
  let unavailable = false;
  const commits: RecordOps[] = [];
  return {
    disk,
    commits,
    failNextCommit(reason) {
      failNext = reason;
    },
    makeUnavailable() {
      unavailable = true;
    },
    read(): Promise<ReadResult> {
      if (unavailable) return Promise.resolve({ ok: false, reason: 'unavailable', error: 'blocked' });
      const records = new Map<StoreName, Map<string, unknown>>();
      for (const [store, map] of disk.records) records.set(store, new Map(structuredClone([...map])));
      return Promise.resolve({ ok: true, meta: disk.meta === null ? null : { ...disk.meta }, records });
    },
    commit(ops: RecordOps, baseRevision: number, schemaVersion: number): Promise<CommitResult> {
      const stored = disk.meta?.revision ?? 0;
      if (stored !== baseRevision) return Promise.resolve({ ok: false, reason: 'stale', revision: stored });
      if (failNext !== null) {
        const reason = failNext;
        failNext = null;
        return Promise.resolve({ ok: false, reason, error: `memory backend: ${reason}` });
      }
      if (ops.clear) for (const store of ALL_STORES) disk.records.delete(store);
      const at = (store: StoreName): Map<string, unknown> => {
        let map = disk.records.get(store);
        if (map === undefined) {
          map = new Map();
          disk.records.set(store, map);
        }
        return map;
      };
      // structuredClone: what IndexedDB stores is a copy, never the live object.
      for (const p of ops.puts) at(p.store).set(p.key, structuredClone(p.value));
      for (const d of ops.deletes) at(d.store).delete(d.key);
      disk.meta = { schemaVersion, revision: baseRevision + 1 };
      commits.push(structuredClone(ops));
      return Promise.resolve({ ok: true, revision: baseRevision + 1 });
    },
    announce(revision: number): void {
      for (const l of disk.listeners) if (l.from !== self) l.listener(revision);
    },
    onAnnounce(listener: (revision: number) => void): () => void {
      const entry = { from: self, listener };
      disk.listeners.add(entry);
      return () => {
        disk.listeners.delete(entry);
      };
    },
    readLegacy(): string | null {
      return disk.legacy;
    },
    removeLegacy(): void {
      disk.legacy = null;
    },
  };
}

export function appRecords(disk: MemoryDisk): Map<string, unknown> {
  return disk.records.get(APP_STORE) ?? new Map<string, unknown>();
```

```ts
export type LoadOutcome =
  | {
      ok: true;
      state: AppState;
      /** [commits] The stored revision this state was read at; 0 when nothing is stored yet. */
      revision: number;
      quarantine: readonly QuarantinedRecord[];
      repairs: readonly Repair[];
      preserved: Preserved;
      /** True when this boot imported fti.v3 into the empty database. */

/**
 * Reads the stored records into a document (spec R13). On a database nothing has written yet,
 * imports fti.v3 first, in ONE transaction that refuses if another instance imported meanwhile,
 * and leaves fti.v3 exactly as it was, as a fallback backup (AGENTS.md rule 7). Never throws.
 */
export async function loadDocument(backend: RecordBackend, attempt = 0): Promise<LoadOutcome> {
  const read = await backend.read();
  if (!read.ok) {
    return { ok: false, reason: 'unavailable', error: read.error, raw: backend.readLegacy(), revision: 0 };
  }
  if (read.meta === null) {
    const text = backend.readLegacy();
    if (text === null) return { ok: false, reason: 'absent', revision: 0 };
    const imported = await importLegacy(backend, text);
    if (imported === 'stale' && attempt === 0) return loadDocument(backend, 1);
    if (imported === 'stale') {
      return { ok: false, reason: 'unavailable', error: 'the database kept changing during the import', raw: text, revision: 0 };
    }
    if (!imported.ok) return { ...imported, raw: text, revision: 0 };
    const assembled = assembleState(groupRecords(imported.puts));
    if (!assembled.ok) return { ok: false, reason: 'invalid', error: assembled.error, raw: text, revision: imported.revision };
    return { ...assembled, revision: imported.revision, imported: true };
  }
  const raw = (): string => rawDocumentText(read.meta, read.records);
  if (read.meta.schemaVersion > CURRENT_SCHEMA_VERSION) {
    return {
      ok: false,
      reason: 'invalid',
      error: `saved by a newer version of the app (schema ${String(read.meta.schemaVersion)}, this build understands ${String(CURRENT_SCHEMA_VERSION)})`,
      raw: raw(),
      revision: read.meta.revision,
    };
  }
  const assembled = assembleState(read.records);
  if (!assembled.ok) return { ok: false, reason: 'invalid', error: assembled.error, raw: raw(), revision: read.meta.revision };
  return { ...assembled, revision: read.meta.revision, imported: false };
}

type ImportOutcome =
  | { ok: true; revision: number; puts: RecordPut[] }
  | { ok: false; reason: 'invalid' | 'unavailable'; error: string }
  | 'stale';

/** fti.v3 -> raw records, written verbatim (unknown keys and invalid records included). */
async function importLegacy(backend: RecordBackend, text: string): Promise<ImportOutcome> {
  let doc: unknown;
  try {
    doc = JSON.parse(text);
  } catch (e) {
    return { ok: false, reason: 'invalid', error: `stored document is not JSON: ${messageOf(e)}` };
  }
  if (typeof doc !== 'object' || doc === null || Array.isArray(doc)) {
    return { ok: false, reason: 'invalid', error: 'not a JSON object' };
  }
  const version: unknown = Reflect.get(doc, 'schemaVersion');
  if (typeof version !== 'number' || !Number.isInteger(version)) {
    return { ok: false, reason: 'invalid', error: 'missing or non-integer schemaVersion' };
  }
  const migrated = migrate(doc, version, CURRENT_SCHEMA_VERSION);
  if (!migrated.ok) return { ok: false, reason: 'invalid', error: migrated.error };
  if (typeof migrated.value !== 'object' || migrated.value === null) {
    return { ok: false, reason: 'invalid', error: 'not a JSON object' };
  }
  const split = splitDocument(migrated.value as Record<string, unknown>);
  if (!split.ok) return { ok: false, reason: 'invalid', error: split.error };
  const committed = await backend.commit({ clear: false, puts: split.puts, deletes: [] }, 0, CURRENT_SCHEMA_VERSION);
  if (committed.ok) return { ok: true, revision: committed.revision, puts: split.puts };
  if (committed.reason === 'stale') return 'stale';
  return { ok: false, reason: 'unavailable', error: committed.error };
}
```

```ts
/** Audit B03: re-reads the records another instance changed; this instance's unsaved batch goes. */
async function reloadFrom(e: Engine): Promise<void> {
  if (engine !== e) return;
  e.queued = null;
  e.dirty = null;
  const outcome = await loadDocument(e.backend);
  if (engine !== e) return;
  installOutcome(outcome);
  e.revision = outcome.revision;
  e.preserved = outcome.ok ? outcome.preserved : EMPTY_PRESERVED;
}

function queueOps(ops: RecordOps): void {
  const e = engine;
  if (e === null) return;
  e.queued = e.queued === null ? ops : mergeOps(e.queued, ops);
  if (e.flushScheduled) return;
  e.flushScheduled = true;
  // One transaction per action: everything the current task changed, then commit.
  queueMicrotask(() => {
    flushQueued(e);
  });
}

function flushQueued(e: Engine): void {
  e.flushScheduled = false;
  if (engine !== e) return;
  const batch = e.queued;
  e.queued = null;
  if (batch === null) return;
  const encoded = encodeOps(batch, e.preserved);
  e.chain = e.chain.then(() => commitBatch(e, encoded));
}

async function commitBatch(e: Engine, batch: RecordOps): Promise<void> {
  if (engine !== e) return;
  const ops = e.dirty === null ? batch : mergeOps(e.dirty, batch);
  e.dirty = null;
  if (isEmptyOps(ops)) return;
  const result = await e.backend.commit(ops, e.revision, CURRENT_SCHEMA_VERSION);
  if (engine !== e) return;
  if (result.ok) {
    e.revision = result.revision;
    if (ops.clear && e.removeLegacyAfterClear) {
      e.removeLegacyAfterClear = false;
      e.backend.removeLegacy();
    }
    e.backend.announce(result.revision);
    useAppStore.getState().reportSaveResult({ ok: true });
    return;
  }
  if (result.reason === 'stale') {
    await reloadFrom(e);
    return;
  }
  // Kept, so the next commit (or Retry) writes it: per-record writes must not lose a change.
  e.dirty = ops;
  useAppStore.getState().reportSaveResult({ ok: false, reason: result.reason, error: result.error });
}

/**
 * Resolves once every change made so far has been committed (or has failed and been reported).
 * For the wipe's ordering (audit B14) and for tests.
 */
export async function whenPersisted(): Promise<void> {
  for (;;) {
    const e = engine;
    if (e === null) return;
    if (e.flushScheduled) flushQueued(e);
    const chain = e.chain;
    await chain;
    if (engine !== e || (e.chain === chain && !e.flushScheduled)) return;
  }
}
```

```ts
/**
 * The stored records as export text for a recovery screen (audit B04: the backup is what is
 * stored, not the in-memory default); fti.v3 while the database holds nothing. Never throws.
 */
export async function readStoredText(backend: RecordBackend = createBrowserBackend()): Promise<string | null> {
  const read = await backend.read();
  if (read.ok && read.meta !== null) return rawDocumentText(read.meta, read.records);
  return backend.readLegacy();
}

/**
 * Empties every record store and removes fti.v3 without going through the store: the root
 * boundary's clear, which must work when the store is what failed. Resolves true when the
 * database clear committed.
 */
export async function clearDatabase(backend: RecordBackend = createBrowserBackend()): Promise<boolean> {
  const read = await backend.read();
  const base = read.ok ? (read.meta?.revision ?? 0) : 0; // [commits]
  const result = await backend.commit({ clear: true, puts: [], deletes: [] }, base, CURRENT_SCHEMA_VERSION);
  backend.removeLegacy();
  if (result.ok) backend.announce(result.revision);
  return result.ok;
}
```

```ts
function withinMs<T>(p: Promise<T>, ms: number): Promise<T> {
  return new Promise<T>((resolve, reject) => {
    const timer = setTimeout(() => {

        resolve(value);

        reject(error instanceof Error ? error : new Error(String(error)));

    );
```

```ts
// src/store/db/quota.ts
//
// Audit B05: warn before the origin's storage quota is reached, not after the first refused
// write. The estimate covers the whole origin (records, the clip, other projects on the same
// GitHub Pages origin), which is the quota a write actually competes for.

/**
 * [dimensionless] usage/quota at which the app warns. An engineering bound, not a measured
 * threshold: it leaves a fifth of the quota for the export and the next commits.
 */
export const STORAGE_WARN_RATIO = 0.8;

export interface StorageReading {
  usageBytes: number; // [bytes]
  quotaBytes: number; // [bytes]
}

/** The browser's estimate, or null when the API is missing, throws, or reports no quota. */
export async function readStorageEstimate(): Promise<StorageReading | null> {
  const storage: unknown = typeof navigator === 'undefined' ? undefined : Reflect.get(navigator, 'storage');
  const estimate: unknown = typeof storage === 'object' && storage !== null ? Reflect.get(storage, 'estimate') : undefined;
  if (typeof estimate !== 'function') return null;
  try {
    const result: unknown = await (estimate as () => Promise<unknown>).call(storage);
    const usage: unknown = typeof result === 'object' && result !== null ? Reflect.get(result, 'usage') : undefined;
    const quota: unknown = typeof result === 'object' && result !== null ? Reflect.get(result, 'quota') : undefined;
    if (typeof usage !== 'number' || typeof quota !== 'number' || !(quota > 0)) return null;
    return { usageBytes: usage, quotaBytes: quota };
  } catch {
    return null;
  }
}

export function nearQuota(reading: StorageReading | null): boolean {
  return reading !== null && reading.usageBytes / reading.quotaBytes >= STORAGE_WARN_RATIO;
}
```

```ts
/** Every record in the page's IndexedDB `fti`, by store then key, and the meta record. */
export async function readRecords(page: Page): Promise<{ meta: unknown; stores: Record<string, Record<string, unknown>> }> {
  const stores = await page.evaluate(async (name) => {
    const db = await new Promise<IDBDatabase>((resolve, reject) => {
      const request = indexedDB.open(name);
      request.onsuccess = () => {
        resolve(request.result);
      };
      request.onerror = () => {
        reject(request.error ?? new Error('open failed'));
      };
    });
    const out: Record<string, Record<string, unknown>> = {};
    const names = Array.from({ length: db.objectStoreNames.length }, (_, i) => db.objectStoreNames.item(i) ?? '');
    for (const store of names) {
      const os = db.transaction(store, 'readonly').objectStore(store);
      const read = <T,>(request: IDBRequest<T>): Promise<T> =>
        new Promise<T>((resolve, reject) => {
          request.onsuccess = () => {
            resolve(request.result);
          };
          request.onerror = () => {
            reject(request.error ?? new Error('read failed'));
          };
        });
      const [keys, values] = await Promise.all([read(os.getAllKeys()), read(os.getAll())]);
      out[store] = Object.fromEntries(keys.map((key, i): [string, unknown] => [String(key), values[i]]));
    }
    db.close();
    return out;
  }, RECORD_DB_NAME);
  return { meta: stores[RECORD_APP_STORE]?.[RECORD_META_KEY] ?? null, stores };
}

/** The stored records as one RAW document (unvalidated), for assertions. Throws before an import. */
export async function readDocument(page: Page): Promise<AppState> {
  const { meta, stores } = await readRecords(page);
  if (meta === null) throw new Error(`no records in IndexedDB ${RECORD_DB_NAME}`);
  const doc: Record<string, unknown> = { schemaVersion: Reflect.get(meta as object, 'schemaVersion') };
  for (const store of RECORD_MAP_STORES) doc[store] = stores[store] ?? {};
  for (const key of RECORD_SINGLETONS) doc[key] = stores[RECORD_APP_STORE]?.[key] ?? null;
  return doc as unknown as AppState;
}

/** [commits] The stored revision, 0 before anything is written. */
async function revisionOf(page: Page): Promise<number> {
  const { meta } = await readRecords(page);
  const revision: unknown = typeof meta === 'object' && meta !== null ? Reflect.get(meta, 'revision') : 0;
  return typeof revision === 'number' ? revision : 0;
}

/**
 * Waits until every commit has landed: spec R13 commits each action at once (no debounce), so
 * this polls the revision until two reads 150 ms apart agree (at most 7.5 s). Node's timer, so
 * the page's fake clock does not affect it.
 */
export async function flushWrites(page: Page): Promise<void> {
  let last = -1;
  for (let i = 0; i < 50; i += 1) {
    const revision = await revisionOf(page);
    if (revision === last) return;
    last = revision;
    await new Promise((resolve) => setTimeout(resolve, 150)); // [ms]
  }
  throw new Error('writes did not settle within 7.5 s');
}

/** Rewrites one stored record behind the app's back, as disk corruption or a newer build would. */
export async function corruptRecord(page: Page, store: string, key: string, patch: Record<string, unknown>): Promise<void> {
  await page.evaluate(
    async ({ name, store: s, key: k, patch: p }) => {
      const db = await new Promise<IDBDatabase>((resolve, reject) => {
        const request = indexedDB.open(name);
        request.onsuccess = () => {
          resolve(request.result);
        };
        request.onerror = () => {
          reject(request.error ?? new Error('open failed'));
        };
      });
      const tx = db.transaction(s, 'readwrite');
      const os = tx.objectStore(s);
      const get = os.get(k);
      get.onsuccess = () => {
        os.put({ ...(get.result as Record<string, unknown>), ...p }, k);
      };
      await new Promise<void>((resolve, reject) => {
        tx.oncomplete = () => {
          resolve();
        };
        tx.onerror = () => {
          reject(tx.error ?? new Error('write failed'));
        };
      });
      db.close();
    },
    { name: RECORD_DB_NAME, store, key, patch },
  );
}
```
