# P6 Rest Games Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the rest game out of the Train header into a bottom sheet that leaves the next set loggable, redesign Rest Word for one-handed phone use, and add four original game families behind a per-rest picker.

**Architecture:** Pure, seeded engines in `src/domain/fun/` (one per family, plus a registry `restGames.ts` that owns the shared seed, difficulty and round clock). Each game is a React component with the one props contract `RestGameProps`, drawn inside a shared `RestGameFrame` (title, round clock, Hide, Exit, end state). `RestTimerPanel` stays the only reader of the rest timer and hands it to `RestGameSheet`, a non-modal fixed bottom sheet that shows a picker, then one round. All rest-game CSS lives in its own sheet `src/ui/styles/restGames.css`.

**Tech Stack:** React 19, TypeScript 5.9 (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vite 8, Zustand 5 (read only here), Vitest 4 + Testing Library (jsdom), plain CSS with tokens.

**Spec:** `docs/plans/2026-11-04-aaa-rebuild-spec.md` (ruling R10, phase P6) and `docs/design/rest-games.md` (constraints 1-7, "Adding a second game family"). Audit finding C14: `docs/private/audit-2026-11-04/C-training.md:86-89` (local only).

## Decisions

**D1 Sheet height (the C14 fix).** A non-modal bottom sheet, `position: fixed` at the bottom edge, `max-height: calc(100svh - 12rem)` (a `100vh` line first), content scrolls inside it if taller, plus a one-tap **Hide Game** control that collapses it to a 60 px bar (44 px **Show Game** button + 2 x 8 px padding, plus the bottom safe area).
- Arithmetic at 390 x 664 CSS px: sheet at most 664 - 192 = **472 px**; the band above it is 12rem = **192 px**. That band must hold the sticky top bar (`src/app/appShell.css:2-17`: 10 + 10 px padding, a 13 px brand line about 16 px tall, 1 px border: about 37 px) and one unlogged set row (`src/ui/styles/train.css:269-290`: marker line about 13 px, field label about 16 px + 44 px input, 44 px Log, two 8 px gaps: about 133 px). 37 + 133 = 170 <= 192. Both heights are read from CSS, not measured; Task 11 measures them in Chromium.
- Rest Word inside 472 px: sheet edge 10 (2 border + 8 padding) + header 44 + 6 + rule 18 + 6 + legend 18 + 6 + grid + 8 + keyboard 140 (3 x 44 + 2 x 4) + 8 bottom padding = 264 px of chrome (16.5rem). Six rows with five 4 px gaps take the rest: (472 - 264 - 20) / 6 = 31.3 px a tile. Total 264 + 20 + 6 x 31.3 = 472.
- The page under the sheet gets `padding-bottom` equal to the sheet's cap (body class `rest-sheet-open`), so every set row can be scrolled above the sheet.
- Rejected: `ModalShell` (`src/ui/components/ModalShell.tsx:81-159`) as the host: its backdrop, focus trap and body scroll lock would block logging the next set, which `TrainView.test.tsx:1892` ("logs the next set with the game open") requires. Rejected: minimise-only (every set would cost a tap to reveal the row). Rejected: a full-height overlay (hides the Log button). Rejected: keeping the board in the header (C14 itself).

**D2 QWERTY width rule.** One CSS grid of 20 half-columns, `column-gap: 0.25rem` (4 px). A letter spans 2 half-columns (key = 2c + 4 px), row 2 starts one half-column in (9 keys centred), row 3 is Enter (3) + Z..M (14) + Del (3) = 20. Keyboard width W = viewport - 2 x 12 px sheet padding; c = (W - 19 x 4) / 20. Keys: 320 px -> 26.0 px wide, 360 -> 30.0, 390 -> 33.0, 412 -> 35.2; all 44 px tall. 26 px >= 24 px, the WCAG 2.2 SC 2.5.8 (Level AA) minimum ("at least 24 by 24 CSS pixels", https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html, read 2026-11-04). This replaces rest-games.md constraint 7 (44 x 44 keys, alphabetical): a 10-key QWERTY row cannot hold 44 px keys under 458 px. Rejected: alphabetical 6-column keys (the owner's complaint), two-row compressed QWERTY (not QWERTY).

**D3 svh, not dvh.** MDN (https://developer.mozilla.org/en-US/docs/Web/CSS/length, read 2026-11-04): small viewport units are "fixed, and therefore stable" while dynamic units "can cause the content to resize while a user is scrolling". caniuse (https://caniuse.com/viewport-unit-variants, read 2026-11-04): Safari iOS 15.4+, Chrome desktop 108+. A `vh` declaration precedes every `svh` one as the fallback.

**D4 Game choice per rest.** The picker lists all five families; the first one is the user's last pick in this lifting session (`sessionId`), else the family derived from the set (`seededFamily`, seed `family:exerciseId:assignmentDate:sessionId:setNumber`; over set numbers 1-20 of one context all five families occur, measured). One tap starts one round; the round's family cannot be switched. **Not Now** closes the picker without spending the round. The last pick is kept in module memory (`restGameChoice.ts`), lost on reload. Rejected: the session slice (the brief allows no store write except `recordRestGameWin`); sessionStorage (AGENTS rule 6).

**D5 Back and Escape.** Opening the sheet pushes one history entry marked `{ ftiRestGameSheet: true }`; `popstate` to an unmarked entry closes it; closing by any other route steps back over its own entry. Escape closes it unless an `[aria-modal="true"]` dialog is open above it. Rejected: waiting for P4's router (until then Android Back would leave the app with the sheet up). P4 (R6 overlay stack) must absorb `useSheetDismiss.ts`.

**D6 One round clock for every family.** `restRoundClockS(restS)`: 45 s for rests <= 90 s, 60 s for <= 120 s, 90 s above, at most half of each band's top (moved from `restWord.ts:37-41`). One clock means one "does it fit" check for the whole picker.

**D7 Store-free games.** Games read the profile units through `RestGameHostContext` (provided by the sheet from `RestTimerPanel`), not from the store, so Task 10 can assert that no game source imports `src/store`.

```ts
//
// The rest games' CSS guarantees (ROADMAP F1, P6, docs/design/rest-games.md), asserted in the
// sheet's own text: jsdom performs no layout and evaluates no media query, the same reason
// src/ui/components/Marquee.test.tsx and src/app/topbar.test.ts read their sheets this way.

import { describe, expect, it } from 'vitest';
import gamesCss from '../../styles/restGames.css?raw';
import trainCss from '../../styles/train.css?raw';

interface Rule {
  selector: string;
  body: string;
}

/** Innermost `selector { body }` pairs; an @media wrapper is dropped, its rules are kept. */
function rulesOf(css: string): Rule[] {
  const withoutComments = css.replace(/\/\*[\s\S]*?\*\//g, '');
  return [...withoutComments.matchAll(/([^{}]+)\{([^{}]*)\}/g)].map((m) => ({
    selector: (m[1] ?? '').trim(),
    body: m[2] ?? '',
  }));
}

/** The text of the block opened by `at`, up to its matching closing brace. */
function blockAt(css: string, at: number): string {
  const open = css.indexOf('{', at);
  let depth = 0;
  for (let i = open; i < css.length; i += 1) {
    if (css[i] === '{') depth += 1;
    if (css[i] === '}') depth -= 1;
    if (depth === 0) return css.slice(open + 1, i);
  }
  return '';
}

/** Any class a rest-game rule names. train.css must hold none of them after the move. */
const GAME_SELECTOR = /\.rest-(game|word|loss|sheet|picker|plate|react|seq|anagram)/;
const gameRules = rulesOf(gamesCss);

/** [px per rem] The 16 px root the 44 px target rule in views.css is written against. */
const PX_PER_REM = 16;
/** [px] The minimum interactive height (views.css: min-height 2.75rem = 44 px). */
const TARGET_PX = 44;

function remOf(body: string, property: string): number | null {
  const m = new RegExp(`(?:^|;|\\s)${property}:\\s*([\\d.]+)rem`).exec(body);
  return m === null ? null : Number(m[1]);
}

describe('rest game styles (ROADMAP F1)', () => {
  it('has rules to check', () => {
    expect(gameRules.length).toBeGreaterThan(0);
  });

  it('keeps every rest-game rule out of train.css', () => {
    const left = rulesOf(trainCss)
      .filter((rule) => GAME_SELECTOR.test(rule.selector))
      .map((rule) => rule.selector);
    expect(left).toEqual([]);
  });

  it('stops every rest-game animation under prefers-reduced-motion', () => {
    const animated = gameRules
      .filter((rule) => /(^|;|\s)animation:\s*(?!none)/.test(rule.body))
      .map((rule) => rule.selector);
    expect(animated.length).toBeGreaterThan(0);

    const reduced = [...gamesCss.matchAll(/@media\s*\(prefers-reduced-motion:\s*reduce\)/g)]
      .map((m) => blockAt(gamesCss, m.index))
      .join('\n');
    const stopped = rulesOf(reduced)
      .filter((rule) => /animation:\s*none/.test(rule.body))
      .flatMap((rule) => rule.selector.split(',').map((s) => s.trim()));
    for (const selectorList of animated) {
      for (const selector of selectorList.split(',').map((s) => s.trim())) {
        expect({ selector, stopped: stopped.includes(selector) }).toEqual({ selector, stopped: true });
      }
    }
  });

  it('makes every on-screen key at least 44 by 44 px', () => {

    expect((remOf(body, 'min-height') ?? 0) * PX_PER_REM).toBeGreaterThanOrEqual(TARGET_PX);
  });
```

```ts
export const REST_GAME_FAMILIES: readonly RestGameFamily[] = [
  'restWord',
  'plateMath',
  'reaction',
  'sequenceRecall',
  'gymAnagram',
];

/** A stable non-cryptographic hash (FNV-1a, 32 bit); repeatability, not secrecy, is the requirement. */
export function restGameSeed(value: string): number {
  let hash = 2_166_136_261;
  for (let i = 0; i < value.length; i += 1) {
    hash ^= value.charCodeAt(i);
    hash = Math.imul(hash, 16_777_619);
  }
  return hash >>> 0;
}

 * The round clock every family uses, so a round fits inside the SHORTEST rest that offers it.
 * Each value is at most half of its band's top (45 of 90, 60 of 120, 90 of 180), so recovery time
 * remains. Moved from restWord.ts (baseRoundForRest), values unchanged.

 * @returns the round clock [s]
 */
export function restRoundClockS(restS: number): number {
  if (restS <= 90) return 45; // [s]
  if (restS <= 120) return 60; // [s]
  return 90; // [s]
}

    restGameSeed(
```

```ts
// src/ui/views/train/useRoundClock.ts
//
// One round's countdown (P6). The deadline is the earlier of the round clock and the rest's end,
// read from the CURRENT timer each render, so a round can never outlive the rest it is in. The
// interval only forces a re-render; the value is recomputed from Date.now() (the RestTimerPanel
// rule, code review A31), and visibilitychange recomputes at once after a backgrounded spell.
//
// Units: instants [ms] epoch UTC; durations [s].
import { useEffect, useState } from 'react';
import type { RestTimer } from '../../../domain/training/restTimer';

const TICK_MS = 1000; // [ms]
const MS_PER_S = 1000; // [ms/s]
const S_PER_MIN = 60; // [s/min]

export interface RoundClock {
  remainingS: number; // [s] >= 0, rounded up
  minutes: number; // [min]
  seconds: number; // [s] 0-59
}

export function useRoundClock(timer: RestTimer, roundS: number): RoundClock {
  const [openedAt] = useState<number>(() => Date.now()); // [ms] epoch UTC
  const [now, setNow] = useState<number>(() => Date.now()); // [ms] epoch UTC

  useEffect(() => {
    const tick = (): void => {
      setNow(Date.now()); // [ms] epoch UTC
    };
    const id = window.setInterval(tick, TICK_MS);
    document.addEventListener('visibilitychange', tick);
    return () => {
      window.clearInterval(id);
      document.removeEventListener('visibilitychange', tick);
    };
  }, []);

  const endsAt = Math.min(openedAt + roundS * MS_PER_S, timer.endsAt); // [ms] epoch UTC
  const remainingS = Math.max(0, Math.ceil((endsAt - now) / MS_PER_S)); // [s]
  return {
    remainingS,
    minutes: Math.floor(remainingS / S_PER_MIN), // [min]
    seconds: remainingS % S_PER_MIN, // [s]
  };
}
```

```tsx
// clear end state after it (won, lost, out of time) with the owner's sprite, the answer on a loss
// and an optional note. Exit is always enabled (rest-games.md constraint 2).
import { useId, type ReactElement, type ReactNode, type Ref } from 'react';
import { FORMAT, type CopyKey } from '../../../content/copy';
import { REST_GAME_FORMAT } from '../../../content/restGameFormat';
import { OwnerSprite } from '../../components/OwnerSprite';
import { LossChomp } from './PixelMascot';
import { useRestGameHost } from './restGameHost';
import type { RoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export type RestGameResult = 'won' | 'lost' | 'timeUp' | null;

export interface RestGameFrameProps {
  /** The game's own class on the section, e.g. 'rest-word'. */
  variant: string;
  titleKey: CopyKey;
  ruleKey: CopyKey;
  t: (key: CopyKey) => string;
  overrides: Readonly<Partial<Record<CopyKey, string>>>;
  clock: RoundClock;
  result: RestGameResult;
  /** Revealed when the round is lost or runs out; null for a game with no single answer. */
  answer: string | null;
  /** Shown in every end state (a best time, a reached length); null for none. */
  endNote: string | null;
  /** The live line during play (progress); '' for none. */
  status: string;
  onExit: () => void;
  sectionRef?: Ref<HTMLElement>;
  children: ReactNode;
}

/* "Round won." and "Round lost." are the Rest Word strings; they say nothing word-specific, so
   every family reads them rather than carrying a copy (AGENTS rule 2). */
const RESULT_KEY: Readonly<Record<Exclude<RestGameResult, null>, CopyKey>> = {
  won: 'status.restWordWon',
  lost: 'status.restWordLost',
  timeUp: 'status.restGameTimeUp',
};

export function RestGameFrame(props: RestGameFrameProps): ReactElement {
  const { t, overrides, clock, result } = props;
  const host = useRestGameHost();
  const titleId = useId();

  return (
    <section
      ref={props.sectionRef}
      className={`rest-game ${props.variant} result-${result ?? 'active'}`}
      aria-labelledby={titleId}
    >
      <div className="rest-game-topline">
        <div className="rest-game-heading">
          <h3 id={titleId}>{t(props.titleKey)}</h3>
          <span className="rest-game-clock" role="timer">
            {FORMAT.restRemaining(clock.minutes, clock.seconds, overrides)}
          </span>
        </div>
        <div className="rest-game-actions">
          {host.onHide !== null && (
            <button type="button" className="rest-game-hide" onClick={host.onHide}>
              {t('button.restGameHide')}
            </button>
          )}
          {/* Always enabled: the round can be left at any moment, won, lost or mid-move. */}
          <button type="button" className="rest-game-exit" onClick={props.onExit}>
            {t('button.restWordExit')}
          </button>
        </div>
      </div>

      {result === null ? (
        <>
          <p className="rest-game-rule">{t(props.ruleKey)}</p>
          {props.children}
        </>
      ) : (
        <div className="rest-game-end">
          {/* The owner's sprite (stylize survey item 7): one play on a win, still otherwise. */}
          <span className={`rest-game-mascot rest-game-mascot-${result === 'won' ? 'win' : 'lose'}`}>
            <OwnerSprite play={result === 'won'} />
          </span>
          {result !== 'won' && <LossChomp />}
          {result !== 'won' && props.answer !== null && (
            <p className="rest-game-answer">{REST_GAME_FORMAT.answer(props.answer, overrides)}</p>
          )}
          {props.endNote !== null && <p className="rest-game-note">{props.endNote}</p>}
        </div>
      )}

      <p className="rest-game-result" aria-live="polite">
        {result === null ? props.status : t(RESULT_KEY[result])}
      </p>
    </section>
  );
}
```

```tsx
// src/ui/views/train/RestWordGame.tsx
//
// Rest Word, the first rest game (ROADMAP F1; redesigned in P6, R10). A DOM/CSS board inside
// RestGameFrame: QWERTY keys sized from the sheet's width (restGames.css, plan D2), tiles that say
// their state in words to a screen reader and by shape to the eye (pink solid with an ink bar,
// lime dashed, grey struck through), a round clock, and the answer on a loss. No canvas, media
// element, font request or network call. It reads the rest timer and never writes it.
//
// Units: instants are epoch ms UTC [ms]; durations are seconds [s].
import { Fragment, useEffect, useMemo, useRef, useState, type ReactElement } from 'react';
import type { CopyKey } from '../../../content/copy';
import {
  isRestWordGuess,
  restWordRound,
  scoreRestWordGuess,
  type RestWordRound,
  type RestWordTile,
} from '../../../domain/fun/restWord';
import { playRestGameCue } from '../../audio/restGameAudio';
import { RestGameFrame, type RestGameResult } from './RestGameFrame';
import { useRestGameHost } from './restGameHost';
import { gameContext, type RestGameCopy, type RestGameProps } from './restGameProps';
import { useRoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export const REST_WORD_COPY = {
  titleKey: 'hero.restWord',
  ruleKey: 'advice.restWordRule',
} as const satisfies RestGameCopy;

/** The three on-screen letter rows, top to bottom. Enter opens and Del closes the last row. */
export const REST_WORD_ROWS = ['QWERTYUIOP', 'ASDFGHJKL', 'ZXCVBNM'] as const;

/** The words a scored tile carries beside its colour and its shape (WCAG 1.4.1). */
const TILE_LABEL: Readonly<Record<RestWordTile, CopyKey>> = {
  exact: 'label.restWordExact',
  present: 'label.restWordPresent',
  absent: 'label.restWordAbsent',
};

const LEGEND_ORDER: readonly RestWordTile[] = ['exact', 'present', 'absent'];

/** Kept for callers that named the old props type; every game takes RestGameProps. */
export type RestWordGameProps = RestGameProps;

/**
 * A hardware key belongs to the game only when nothing else claims it: focus on the page body, or
 * inside the sheet that hosts the board (RestGameSheet focuses itself when it opens), or inside the
 * board. Enter on a focused Log Set control, or a letter typed into a set field, is left alone, so
 * the next set always logs with the board open.
 */
function keyIsForGame(event: KeyboardEvent, game: HTMLElement | null): boolean {
  if (event.ctrlKey || event.metaKey || event.altKey) return false;
  const target = event.target;
  if (!(target instanceof Node)) return false;
  if (target === document.body || target === document.documentElement) return true;
  const scope: Element | null = game === null ? null : (game.closest('.rest-sheet') ?? game);
  if (scope === null || !scope.contains(target)) return false;
  return !(target instanceof HTMLInputElement || target instanceof HTMLTextAreaElement);
}

/**
 * One round inside one rest. Its own deadline is the earlier of the round clock and the rest's
 * end; winning, losing and leaving can never pause, skip or extend the prescribed rest.
 */
export function RestWordGame(props: RestGameProps): ReactElement {
  const { timer, priorWins, soundsEnabled, t, overrides, onExit, onWin } = props;
  const host = useRestGameHost();
  const context = gameContext(timer, 'RestWordGame');
  // Frozen for the life of this board: a win raises priorWins for the NEXT rest and must never
  // reshuffle the board the player just solved.
  const [round] = useState<RestWordRound>(() => restWordRound(context, timer.durationS, priorWins));
  const clock = useRoundClock(timer, round.durationS);
  const [guesses, setGuesses] = useState<string[]>([]);
  const [scores, setScores] = useState<readonly (readonly RestWordTile[])[]>([]);
  const [draft, setDraft] = useState('');
  const [result, setResult] = useState<RestGameResult>(null);
  const sectionRef = useRef<HTMLElement>(null);
  const canEnter = result === null && clock.remainingS > 0;

  const keyStates = useMemo(() => {
    const rank: Record<RestWordTile, number> = { absent: 1, present: 2, exact: 3 };
    const byLetter: Partial<Record<string, RestWordTile>> = {};
    scores.forEach((score, guessIndex) => {
      const guess = guesses[guessIndex] ?? '';
      score.forEach((state, letterIndex) => {
        const letter = guess[letterIndex];
        if (letter === undefined) return;
        const old = byLetter[letter];
        if (old === undefined || rank[state] > rank[old]) byLetter[letter] = state;
      });
    });
    return byLetter;
  }, [guesses, scores]);

  useEffect(() => {
    if (result !== null || clock.remainingS > 0) return;
    setResult('timeUp');
    playRestGameCue('lose', soundsEnabled);
  }, [clock.remainingS, result, soundsEnabled]);

  const appendLetter = (letter: string): void => {
    if (!canEnter || draft.length >= round.wordLength) return;
    setDraft((value) => `${value}${letter.toLowerCase()}`);
  };

  const removeLetter = (): void => {
    if (!canEnter) return;
    setDraft((value) => value.slice(0, -1));
  };

  const submit = (): void => {
    if (!canEnter || !isRestWordGuess(draft, round.wordLength)) return;
    const score = scoreRestWordGuess(draft, round.target);
    setGuesses((value) => [...value, draft]);
    setScores((value) => [...value, score]);
    setDraft('');
    if (score.every((tile) => tile === 'exact')) {
      setResult('won');
      playRestGameCue('win', soundsEnabled);
      onWin();
      return;
    }
    if (guesses.length + 1 >= round.maxGuesses) {
      setResult('lost');
      playRestGameCue('lose', soundsEnabled);
      return;
    }
    playRestGameCue('submit', soundsEnabled);
  };

  useEffect(() => {
    const onKeyDown = (event: KeyboardEvent): void => {
      if (host.hidden || !keyIsForGame(event, sectionRef.current)) return;
      if (event.key === 'Enter') {
        event.preventDefault();
        submit();
        return;
      }
      if (event.key === 'Backspace') {
        event.preventDefault();
        removeLetter();
        return;
      }
      if (/^[a-z]$/i.test(event.key)) {
        event.preventDefault();
        appendLetter(event.key);
      }
    };
    window.addEventListener('keydown', onKeyDown);
    return () => {
      window.removeEventListener('keydown', onKeyDown);
    };
  });

  const keyClass = (letter: string, offset: boolean): string =>
    ['rest-word-key', offset ? 'rest-word-offset' : '', keyStates[letter.toLowerCase()] ?? '']
      .filter((name) => name !== '')
      .join(' ');

  return (
    <RestGameFrame
      variant="rest-word"
      {...REST_WORD_COPY}
      t={t}
      overrides={overrides}
      clock={clock}
      result={result}
      answer={round.target}
      endNote={null}
      status=""
      onExit={onExit}
      sectionRef={sectionRef}
    >
      {/* Decorative for a screen reader: every scored tile already says its state. */}
      <div className="rest-word-legend" aria-hidden="true">
        {LEGEND_ORDER.map((state) => (
          <span className="rest-word-legend-item" key={state}>
            <span className={`rest-word-tile rest-word-tile-mini ${state}`}>A</span>
            {t(TILE_LABEL[state])}
          </span>
        ))}
      </div>

      <div className="rest-word-grid" role="group" aria-label={t('label.restWordBoard')}>
        {Array.from({ length: round.maxGuesses }, (_, rowIndex) => {
          const guess = guesses[rowIndex] ?? (rowIndex === guesses.length ? draft : '');
          const score = scores[rowIndex];
          return (
            <div className="rest-word-row" key={rowIndex}>
              {Array.from({ length: round.wordLength }, (_, columnIndex) => {
                const letter = (guess[columnIndex] ?? '').toUpperCase();
                const state = score?.[columnIndex];
                return state === undefined ? (
                  <span className="rest-word-tile" key={columnIndex}>
                    {letter}
                  </span>
                ) : (
                  <span
                    className={`rest-word-tile ${state}`}
                    key={columnIndex}
                    role="img"
                    aria-label={`${letter}, ${t(TILE_LABEL[state])}`}
                  >
                    {letter}
                  </span>
                );
              })}
            </div>
          );
        })}
      </div>

      <div className="rest-word-keyboard" role="group" aria-label={t('label.restWordKeyboard')}>
        {REST_WORD_ROWS.map((row, rowIndex) => (
          <Fragment key={row}>
            {rowIndex === 2 && (
              <button
                type="button"
                className="rest-word-key rest-word-wide"
                disabled={!canEnter || draft.length !== round.wordLength}
                onClick={submit}
              >
                {t('button.restWordEnter')}
              </button>
            )}
            {Array.from(row).map((letter, index) => (
              <button
                type="button"
                className={keyClass(letter, rowIndex === 1 && index === 0)}
                disabled={!canEnter}
                key={letter}
                onClick={() => {
                  appendLetter(letter);
                }}
              >
                {letter}
              </button>
            ))}
            {rowIndex === 2 && (
              <button
                type="button"
                className="rest-word-key rest-word-wide"
                disabled={!canEnter}
                onClick={removeLetter}
              >
                {t('button.restWordDel')}
              </button>
            )}
          </Fragment>
        ))}
      </div>
    </RestGameFrame>
  );
}
```

```ts
// src/domain/fun/plateMath.ts
//
// Plate Math (P6, R10): load one side of a bar so the whole bar matches a target. A puzzle in
// plain arithmetic, in the profile's own units; nothing here is a health number or feeds training.
// The arithmetic runs in integer hundredths, so 1.25 kg plates never meet a floating-point miss.
//
// Units: every load is [kg] for a metric round and [lb] for an imperial one, BOTH sides of the bar
// included; a plate is the mass of ONE plate; durations [s].
import type { RestGameContext } from '../training/restTimer';
import type { UnitSystem } from '../types';
import { restGameDifficulty, restGameRng, restRoundClockS } from './restGames';

/** One plate of each size the game offers, heaviest first [kg] or [lb] per plate. */
export const PLATE_MATH_PLATES: Readonly<Record<UnitSystem, readonly number[]>> = {
  metric: [25, 20, 15, 10, 5, 2.5, 1.25], // [kg]
  imperial: [45, 35, 25, 10, 5, 2.5], // [lb]
};

/** The empty bar [kg] or [lb]. */
export const PLATE_MATH_BAR: Readonly<Record<UnitSystem, number>> = { metric: 20, imperial: 45 };

/** Targets per round [targets]. */
export const PLATE_MATH_TARGETS = 3;

/** A side holds at most this many plates [plates]; further taps are ignored. */
export const PLATE_MATH_MAX_PER_SIDE = 12;

const CENTI = 100; // [hundredths per unit]

export interface PlateMathRound {
  units: UnitSystem;
  bar: number; // [kg] or [lb]
  plates: readonly number[]; // [kg] or [lb] per plate, heaviest first
  targets: readonly number[]; // [kg] or [lb] whole bar, both sides
  durationS: number; // [s] the round clock
  difficulty: number; // [tier] 0-3
}

function centi(value: number): number {
  return Math.round(value * CENTI);
}

/** The whole bar: the bar plus the same plates on both sides [kg] or [lb]. */
export function plateMathLoad(bar: number, side: readonly number[]): number {
  const total = centi(bar) + 2 * side.reduce((sum, plate) => sum + centi(plate), 0); // [hundredths]
  return total / CENTI;
}

/** True when the loaded bar equals the target to the hundredth. */
export function plateMathMatches(target: number, bar: number, side: readonly number[]): boolean {
  return centi(plateMathLoad(bar, side)) === centi(target);
}

/**
 * Three targets, each built from 2 + difficulty seeded plates per side, so every target is
 * reachable with the plates on offer.
 *
 * @param restS [s] the prescribed rest, RestTimer.durationS
 * @param priorWins [rounds] won earlier in this lifting day
 */
export function plateMathRound(
  context: RestGameContext,
  restS: number,
  priorWins: number,
  units: UnitSystem,
): PlateMathRound {
  const difficulty = restGameDifficulty(context, priorWins);
  const plates = PLATE_MATH_PLATES[units];
  const bar = PLATE_MATH_BAR[units];
  const rng = restGameRng('plateMath', context, difficulty);
  const perSide = 2 + difficulty; // [plates]
  const targets: number[] = [];
  for (let i = 0; i < PLATE_MATH_TARGETS; i += 1) {
    const side = Array.from({ length: perSide }, () => plates[Math.floor(rng() * plates.length)] ?? plates[0]!);
    targets.push(plateMathLoad(bar, side));
  }
  return { units, bar, plates, targets, durationS: restRoundClockS(restS), difficulty };
}
```

```tsx
// src/ui/views/train/PlateMathGame.tsx
//
// Plate Math (P6, R10): tap plates onto one side of the bar until the whole bar matches the
// target; three targets a round. Arithmetic only, in the profile's units (RestGameHostContext);
// no health number. It reads the rest timer and never writes it.
//
// Units: loads [kg] for a metric profile, [lb] for an imperial one, both sides included; a plate
// button names ONE plate; instants [ms] epoch UTC; durations [s].
import { useEffect, useState, type ReactElement } from 'react';
import { REST_GAME_FORMAT } from '../../../content/restGameFormat';
import {
  PLATE_MATH_MAX_PER_SIDE,
  plateMathLoad,
  plateMathMatches,
  plateMathRound,
  type PlateMathRound,
} from '../../../domain/fun/plateMath';
import { UNIT_LABEL } from '../../../domain/units';
import { playRestGameCue } from '../../audio/restGameAudio';
import { RestGameFrame, type RestGameResult } from './RestGameFrame';
import { useRestGameHost } from './restGameHost';
import { gameContext, type RestGameCopy, type RestGameProps } from './restGameProps';
import { useRoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export const PLATE_MATH_COPY = {
  titleKey: 'hero.restGamePlateMath',
  ruleKey: 'advice.restGamePlateMathRule',
} as const satisfies RestGameCopy;

/** "62.5 kg": at most two decimals, the 1.25 kg plate's precision. */
function formatLoad(value: number, unit: string): string {
  return `${String(Math.round(value * 100) / 100)} ${unit}`;
}

export function PlateMathGame(props: RestGameProps): ReactElement {
  const { timer, priorWins, soundsEnabled, t, overrides, onExit, onWin } = props;
  const host = useRestGameHost();
  const context = gameContext(timer, 'PlateMathGame');
  // Frozen for the life of this board, units included: a profile edit mid-rest changes nothing.
  const [round] = useState<PlateMathRound>(() =>
    plateMathRound(context, timer.durationS, priorWins, host.units),
  );
  const clock = useRoundClock(timer, round.durationS);
  const [solved, setSolved] = useState(0); // [targets]
  const [side, setSide] = useState<readonly number[]>([]); // [kg] or [lb] per plate, in tap order
  const [result, setResult] = useState<RestGameResult>(null);
  const unit = UNIT_LABEL[round.units].load;
  const target = round.targets[solved] ?? round.targets[round.targets.length - 1] ?? round.bar; // [kg] or [lb]
  const onBar = plateMathLoad(round.bar, side); // [kg] or [lb]
  const canPlay = result === null && clock.remainingS > 0;

  useEffect(() => {
    if (result !== null || clock.remainingS > 0) return;
    setResult('timeUp');
    playRestGameCue('lose', soundsEnabled);
  }, [clock.remainingS, result, soundsEnabled]);

  const addPlate = (plate: number): void => {
    if (!canPlay || side.length >= PLATE_MATH_MAX_PER_SIDE) return;
    const next = [...side, plate];
    if (!plateMathMatches(target, round.bar, next)) {
      setSide(next);
      return;
    }
    const done = solved + 1; // [targets]
    if (done >= round.targets.length) {
      setSide(next);
      setSolved(done);
      setResult('won');
      playRestGameCue('win', soundsEnabled);
      onWin();
      return;
    }
    playRestGameCue('submit', soundsEnabled);
    setSolved(done);
    setSide([]);
  };

  const removePlate = (): void => {
    if (!canPlay) return;
    setSide((value) => value.slice(0, -1));
  };

  return (
    <RestGameFrame
      variant="rest-plate"
      {...PLATE_MATH_COPY}
      t={t}
      overrides={overrides}
      clock={clock}
      result={result}
      answer={null}
      endNote={null}
      status={REST_GAME_FORMAT.progress(solved, round.targets.length, overrides)}
      onExit={onExit}
    >
      <dl className="rest-plate-readout">
        <div>
          <dt>{t('label.restGamePlateTarget')}</dt>
          <dd>{formatLoad(target, unit)}</dd>
        </div>
        <div>
          <dt>{t('label.restGamePlateOnBar')}</dt>
          {/* Over the target reads as a wavy underline as well as by its number (WCAG 1.4.1). */}
          <dd className={onBar > target ? 'rest-plate-over' : undefined}>{formatLoad(onBar, unit)}</dd>
        </div>
      </dl>

      <div className="rest-plate-side" role="group" aria-label={t('label.restGamePlateSide')}>
        {side.map((plate, index) => (
          <span className="rest-plate-chip" key={index}>
            {formatLoad(plate, unit)}
          </span>
        ))}
      </div>

      <div className="rest-plate-rack" role="group" aria-label={t('label.restGamePlates')}>
        {round.plates.map((plate) => (
          <button
            type="button"
            className="rest-plate-add"
            key={plate}
            disabled={!canPlay}
            onClick={() => {
              addPlate(plate);
            }}
          >
            {formatLoad(plate, unit)}
          </button>
        ))}
      </div>

      <button
        type="button"
        className="rest-plate-remove"
        disabled={!canPlay || side.length === 0}
        onClick={removePlate}
      >
        {t('button.restGamePlateRemove')}
      </button>
    </RestGameFrame>
  );
}
```

Note for the implementer: `className={... ? 'rest-plate-over' : undefined}` is allowed under `exactOptionalPropertyTypes` because React's `className` is typed `string | undefined`. If `tsc` refuses it, use `''` instead of `undefined`.

```ts
// src/domain/fun/reaction.ts
//
// Reaction (P6, R10): tap when the pad turns lime. Five trials, each after a seeded wait; a tap
// before the go is a foul, no tap in the go window is a miss, three clean taps win. A game score:
// the times are shown, never judged against a norm.
//
// Units: every time here is milliseconds [ms]; the round clock is seconds [s].
import type { RestGameContext } from '../training/restTimer';
import { restGameDifficulty, restGameRng, restRoundClockS } from './restGames';

export const REACTION_TRIALS = 5; // [trials]
export const REACTION_CLEAN_TO_WIN = 3; // [trials]
export const REACTION_MIN_DELAY_MS = 1200; // [ms] shortest wait before the pad turns lime
export const REACTION_DELAY_SPREAD_MS = 2300; // [ms] waits fall in [1200, 3500)
export const REACTION_FEEDBACK_MS = 700; // [ms] a trial's result stays on the pad this long
const GO_WINDOW_MS = 2000; // [ms] at tier 0
const GO_WINDOW_STEP_MS = 250; // [ms] narrower per tier

export interface ReactionRound {
  trials: number; // [trials]
  delaysMs: readonly number[]; // [ms] one wait per trial
  goWindowMs: number; // [ms]
  feedbackMs: number; // [ms]
  cleanToWin: number; // [trials]
  durationS: number; // [s] the round clock
  difficulty: number; // [tier] 0-3
}

export type ReactionTrial = { kind: 'clean'; ms: number } | { kind: 'foul' } | { kind: 'missed' };

export interface ReactionSummary {
  bestMs: number | null; // [ms] the fastest clean tap, null before one
  clean: number; // [trials]
  fouls: number; // [trials]
  missed: number; // [trials]
  finished: boolean;
  won: boolean;
}

/**
 * @param restS [s] the prescribed rest, RestTimer.durationS
 * @param priorWins [rounds] won earlier in this lifting day
 */
export function reactionRound(context: RestGameContext, restS: number, priorWins: number): ReactionRound {
  const difficulty = restGameDifficulty(context, priorWins);
  const rng = restGameRng('reaction', context, difficulty);
  const delaysMs = Array.from(
    { length: REACTION_TRIALS },
    () => REACTION_MIN_DELAY_MS + Math.floor(rng() * REACTION_DELAY_SPREAD_MS),
  );
  return {
    trials: REACTION_TRIALS,
    delaysMs,
    goWindowMs: GO_WINDOW_MS - GO_WINDOW_STEP_MS * difficulty,
    feedbackMs: REACTION_FEEDBACK_MS,
    cleanToWin: REACTION_CLEAN_TO_WIN,
    durationS: restRoundClockS(restS),
    difficulty,
  };
}

export function reactionSummary(round: ReactionRound, trials: readonly ReactionTrial[]): ReactionSummary {
  let bestMs: number | null = null;
  let clean = 0;
  let fouls = 0;
  let missed = 0;
  for (const trial of trials) {
    if (trial.kind === 'clean') {
      clean += 1;
      bestMs = bestMs === null ? trial.ms : Math.min(bestMs, trial.ms);
    } else if (trial.kind === 'foul') {
      fouls += 1;
    } else {
      missed += 1;
    }
  }
  const finished = trials.length >= round.trials;
  return { bestMs, clean, fouls, missed, finished, won: finished && clean >= round.cleanToWin };
}

/** Every wait in full, every go window run out, every result shown [ms]: the longest round. */
export function reactionWorstCaseMs(round: ReactionRound): number {
  const waits = round.delaysMs.reduce((sum, delay) => sum + delay, 0); // [ms]
  return waits + round.trials * (round.goWindowMs + round.feedbackMs); // [ms]
}
```

```tsx
// src/ui/views/train/ReactionGame.tsx
//
// Reaction (P6, R10): one big pad. Start, wait while it is dark, tap when it turns lime. Five
// trials; three clean taps win. The pad says its state in words and by its edge (dashed while
// waiting, solid ink on lime at go), so colour never stands alone. It reads the rest timer and
// never writes it.
//
// Units: instants [ms] epoch UTC; reaction times and waits [ms]; the round clock [s].
import { useEffect, useRef, useState, type ReactElement } from 'react';
import { REST_GAME_FORMAT } from '../../../content/restGameFormat';
import {
  REACTION_MIN_DELAY_MS,
  reactionRound,
  reactionSummary,
  type ReactionRound,
  type ReactionTrial,
} from '../../../domain/fun/reaction';
import { playRestGameCue } from '../../audio/restGameAudio';
import { RestGameFrame, type RestGameResult } from './RestGameFrame';
import { gameContext, type RestGameCopy, type RestGameProps } from './restGameProps';
import { useRoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export const REACTION_COPY = {
  titleKey: 'hero.restGameReaction',
  ruleKey: 'advice.restGameReactionRule',
} as const satisfies RestGameCopy;

type Phase = 'idle' | 'waiting' | 'go' | 'feedback';

export function ReactionGame(props: RestGameProps): ReactElement {
  const { timer, priorWins, soundsEnabled, t, overrides, onExit, onWin } = props;
  const context = gameContext(timer, 'ReactionGame');
  const [round] = useState<ReactionRound>(() => reactionRound(context, timer.durationS, priorWins));
  const clock = useRoundClock(timer, round.durationS);
  const [phase, setPhase] = useState<Phase>('idle');
  const [trials, setTrials] = useState<readonly ReactionTrial[]>([]);
  const [result, setResult] = useState<RestGameResult>(null);
  const goAtRef = useRef(0); // [ms] epoch UTC, the instant the pad turned lime
  const canPlay = result === null && clock.remainingS > 0;
  const summary = reactionSummary(round, trials);

  const record = (trial: ReactionTrial): void => {
    const next = [...trials, trial];
    setTrials(next);
    const after = reactionSummary(round, next);
    if (!after.finished) {
      setPhase('feedback');
      return;
    }
    setPhase('idle');
    if (after.won) {
      setResult('won');
      playRestGameCue('win', soundsEnabled);
      onWin();
      return;
    }
    setResult('lost');
    playRestGameCue('lose', soundsEnabled);
  };
  // The go-window timeout records a miss through this ref, so the effect below does not re-run
  // on every render for a new `record` closure.
  const recordRef = useRef(record);
  useEffect(() => {
    recordRef.current = record;
  });

  useEffect(() => {
    if (result !== null || clock.remainingS > 0) return;
    setResult('timeUp');
    playRestGameCue('lose', soundsEnabled);
  }, [clock.remainingS, result, soundsEnabled]);

  const trialIndex = trials.length; // [trials] done so far
  useEffect(() => {
    if (result !== null) return undefined;
    let id: number | undefined;
    if (phase === 'waiting') {
      id = window.setTimeout(() => {
        goAtRef.current = Date.now(); // [ms] epoch UTC
        setPhase('go');
      }, round.delaysMs[trialIndex] ?? REACTION_MIN_DELAY_MS);
    } else if (phase === 'go') {
      id = window.setTimeout(() => {
        recordRef.current({ kind: 'missed' });
      }, round.goWindowMs);
    } else if (phase === 'feedback') {
      id = window.setTimeout(() => {
        setPhase('waiting');
      }, round.feedbackMs);
    }
    return () => {
      if (id !== undefined) window.clearTimeout(id);
    };
  }, [phase, result, trialIndex, round]);

  const tap = (): void => {
    if (!canPlay) return;
    if (phase === 'idle') {
      setPhase('waiting');
      return;
    }
    if (phase === 'waiting') {
      record({ kind: 'foul' });
      return;
    }
    if (phase === 'go') {
      record({ kind: 'clean', ms: Math.max(0, Date.now() - goAtRef.current) }); // [ms]
    }
  };

  const trialText = (trial: ReactionTrial): string => {
    if (trial.kind === 'clean') return REST_GAME_FORMAT.reactionTime(trial.ms, overrides);
    return trial.kind === 'foul' ? t('label.restGameReactionFoul') : t('label.restGameReactionMissed');
  };
  const last = trials[trials.length - 1];
  const padText =
    phase === 'idle'
      ? t('button.restGameReactionStart')
      : phase === 'waiting'
        ? t('label.restGameReactionWait')
        : phase === 'go'
          ? t('label.restGameReactionGo')
          : last === undefined
            ? ''
            : trialText(last);

  return (
    <RestGameFrame
      variant="rest-react"
      {...REACTION_COPY}
      t={t}
      overrides={overrides}
      clock={clock}
      result={result}
      answer={null}
      endNote={summary.bestMs === null ? null : REST_GAME_FORMAT.reactionBest(summary.bestMs, overrides)}
      status={REST_GAME_FORMAT.progress(trials.length, round.trials, overrides)}
      onExit={onExit}
    >
      <button type="button" className={`rest-react-pad is-${phase}`} disabled={!canPlay} onClick={tap}>
        {padText}
      </button>
      <ol className="rest-react-trials" aria-label={t('label.restGameReactionTrials')}>
        {trials.map((trial, index) => (
          <li key={index}>{trialText(trial)}</li>
        ))}
      </ol>
    </RestGameFrame>
  );
}
```

```ts
// src/domain/fun/sequenceRecall.ts
//
// Sequence Recall (P6, R10): pads light a growing sequence; repeat it. React-free and clock-free:
// the component owns the timers, this module owns the sequence and the rules.
//
// Units: step, gap and pause times [ms]; the round clock [s]; pads are 0-based indices.
import type { RestGameContext } from '../training/restTimer';
import { restGameDifficulty, restGameRng, restRoundClockS } from './restGames';

export const SEQUENCE_START_LENGTH = 2; // [steps]
export const SEQUENCE_STEP_MS = 450; // [ms] a pad stays lit
export const SEQUENCE_GAP_MS = 250; // [ms] dark between two steps
export const SEQUENCE_PAUSE_MS = 600; // [ms] before each showing
const MIN_PADS = 4; // [pads]
const BASE_GOAL = 5; // [steps] at tier 0

export interface SequenceRound {
  padCount: number; // [pads]
  sequence: readonly number[]; // pad indices, length goalLength
  startLength: number; // [steps]
  goalLength: number; // [steps]
  stepMs: number; // [ms]
  gapMs: number; // [ms]
  pauseMs: number; // [ms]
  durationS: number; // [s] the round clock
  difficulty: number; // [tier] 0-3
}

export type SequenceCheck = 'continue' | 'level' | 'miss';

/**
 * @param restS [s] the prescribed rest, RestTimer.durationS
 * @param priorWins [rounds] won earlier in this lifting day
 */
export function sequenceRound(context: RestGameContext, restS: number, priorWins: number): SequenceRound {
  const difficulty = restGameDifficulty(context, priorWins);
  const padCount = MIN_PADS + Math.min(2, difficulty);
  const goalLength = BASE_GOAL + difficulty;
  const rng = restGameRng('sequenceRecall', context, difficulty);
  const sequence: number[] = [];
  for (let i = 0; i < goalLength; i += 1) {
    const previous = sequence[i - 1];
    if (previous === undefined) {
      sequence.push(Math.floor(rng() * padCount));
      continue;
    }
    // Uniform over the other pads: draw from padCount - 1 and step over the previous one.
    const pick = Math.floor(rng() * (padCount - 1));
    sequence.push(pick >= previous ? pick + 1 : pick);
  }
  return {
    padCount,
    sequence,
    startLength: SEQUENCE_START_LENGTH,
    goalLength,
    stepMs: SEQUENCE_STEP_MS,
    gapMs: SEQUENCE_GAP_MS,
    pauseMs: SEQUENCE_PAUSE_MS,
    durationS: restRoundClockS(restS),
    difficulty,
  };
}

/** The verdict on the taps so far at this level: keep going, level done, or a miss. */
export function checkSequenceInput(
  round: SequenceRound,
  length: number,
  inputs: readonly number[],
): SequenceCheck {
  const last = inputs.length - 1;
  if (last < 0) return 'continue';
  if (inputs[last] !== round.sequence[last]) return 'miss';
  return inputs.length >= length ? 'level' : 'continue';
}

/** Time spent showing every level from the start length to the goal, pauses included [ms]. */
export function sequenceShowMs(round: SequenceRound): number {
  let total = 0; // [ms]
  for (let length = round.startLength; length <= round.goalLength; length += 1) {
    total += round.pauseMs + length * (round.stepMs + round.gapMs);
  }
  return total;
}
```

```tsx
// src/ui/views/train/SequenceRecallGame.tsx
//
// Sequence Recall (P6, R10): numbered pads light a growing sequence; repeat it. A miss ends the
// round lost, the round clock ends it out of time. A lit pad is lime with a double ink edge and
// the status line says Watch or Your Turn, so colour never stands alone. Lighting a pad is the
// game itself, not decoration, so it is a state change with no CSS animation and reduced motion
// leaves it as it is. It reads the rest timer and never writes it.
//
// Units: instants [ms] epoch UTC; step, gap and pause times [ms]; the round clock [s].
import { useEffect, useState, type ReactElement } from 'react';
import { REST_GAME_FORMAT } from '../../../content/restGameFormat';
import { checkSequenceInput, sequenceRound, type SequenceRound } from '../../../domain/fun/sequenceRecall';
import { playRestGameCue } from '../../audio/restGameAudio';
import { RestGameFrame, type RestGameResult } from './RestGameFrame';
import { gameContext, type RestGameCopy, type RestGameProps } from './restGameProps';
import { useRoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export const SEQUENCE_RECALL_COPY = {
  titleKey: 'hero.restGameSequence',
  ruleKey: 'advice.restGameSequenceRule',
} as const satisfies RestGameCopy;

type Phase = 'pause' | 'watch' | 'repeat';

export function SequenceRecallGame(props: RestGameProps): ReactElement {
  const { timer, priorWins, soundsEnabled, t, overrides, onExit, onWin } = props;
  const context = gameContext(timer, 'SequenceRecallGame');
  const [round] = useState<SequenceRound>(() => sequenceRound(context, timer.durationS, priorWins));
  const clock = useRoundClock(timer, round.durationS);
  const [length, setLength] = useState(round.startLength); // [steps]
  const [phase, setPhase] = useState<Phase>('pause');
  const [lit, setLit] = useState<number | null>(null); // the pad lit now, if any
  const [inputs, setInputs] = useState<readonly number[]>([]);
  const [result, setResult] = useState<RestGameResult>(null);
  const canPlay = result === null && clock.remainingS > 0;

  useEffect(() => {
    if (result !== null || clock.remainingS > 0) return;
    setResult('timeUp');
    playRestGameCue('lose', soundsEnabled);
  }, [clock.remainingS, result, soundsEnabled]);

  useEffect(() => {
    if (result !== null) return undefined;
    const ids: number[] = [];
    const strideMs = round.stepMs + round.gapMs; // [ms]
    if (phase === 'pause') {
      ids.push(
        window.setTimeout(() => {
          setPhase('watch');
        }, round.pauseMs),
      );
    } else if (phase === 'watch') {
      for (let i = 0; i < length; i += 1) {
        const pad = round.sequence[i] ?? null;
        ids.push(
          window.setTimeout(() => {
            setLit(pad);
          }, i * strideMs),
        );
        ids.push(
          window.setTimeout(() => {
            setLit(null);
          }, i * strideMs + round.stepMs),
        );
      }
      ids.push(
        window.setTimeout(() => {
          setPhase('repeat');
        }, length * strideMs),
      );
    }
    return () => {
      for (const id of ids) window.clearTimeout(id);
    };
  }, [phase, length, result, round]);

  const tap = (pad: number): void => {
    if (!canPlay || phase !== 'repeat') return;
    const next = [...inputs, pad];
    const check = checkSequenceInput(round, length, next);
    if (check === 'miss') {
      setInputs(next);
      setResult('lost');
      playRestGameCue('lose', soundsEnabled);
      return;
    }
    if (check === 'continue') {
      setInputs(next);
      return;
    }
    if (length >= round.goalLength) {
      setInputs(next);
      setResult('won');
      playRestGameCue('win', soundsEnabled);
      onWin();
      return;
    }
    playRestGameCue('submit', soundsEnabled);
    setInputs([]);
    setLength(length + 1);
    setPhase('pause');
  };

  return (
    <RestGameFrame
      variant="rest-seq"
      {...SEQUENCE_RECALL_COPY}
      t={t}
      overrides={overrides}
      clock={clock}
      result={result}
      answer={null}
      endNote={REST_GAME_FORMAT.sequenceLength(length, round.goalLength, overrides)}
      status={phase === 'repeat' ? t('label.restGameSequenceRepeat') : t('label.restGameSequenceWatch')}
      onExit={onExit}
    >
      <p className="rest-seq-length">{REST_GAME_FORMAT.sequenceLength(length, round.goalLength, overrides)}</p>
      <div
        className={`rest-seq-grid pads-${String(round.padCount)}`}
        role="group"
        aria-label={t('label.restGameSequencePads')}
      >
        {Array.from({ length: round.padCount }, (_, pad) => (
          <button
            type="button"
            key={pad}
            className={lit === pad ? 'rest-seq-pad is-lit' : 'rest-seq-pad'}
            aria-label={REST_GAME_FORMAT.sequencePad(pad + 1, overrides)}
            disabled={!canPlay || phase !== 'repeat'}
            onClick={() => {
              tap(pad);
            }}
          >
            {pad + 1}
          </button>
        ))}
      </div>
    </RestGameFrame>
  );
}
```

```ts
// src/domain/fun/gymAnagram.ts
//
// Gym Anagram (P6, R10): unscramble a gym word. The bank is source text (offline, a few hundred
// bytes, no third-party word list or licence), written by hand from plain gym vocabulary.
//
// Units: word lengths [letters]; the round clock [s].
import type { RestGameContext } from '../training/restTimer';
import { restGameDifficulty, restGameRng, restRoundClockS } from './restGames';

/*
 * By length. Left out on purpose because their letters also spell another common word, which the
 * game would then refuse: hinge (neigh), swing (wings), plates (staple), clean (lance), snatch
 * (chants), spotter (protest), sprint (prints).
 */
const GYM_WORDS: Readonly<Record<number, readonly string[]>> = {
  5: ['bench', 'cable', 'chalk', 'glute', 'lunge', 'plank', 'press', 'shrug', 'squat', 'tempo'],
  6: ['biceps', 'cardio', 'collar', 'pullup', 'rowing', 'warmup'],
  7: ['barbell', 'chinups', 'pushups', 'stretch', 'triceps'],
  8: ['cooldown', 'deadlift', 'dumbbell', 'overhead'],
};

export const GYM_ANAGRAM_MIN_LENGTH = 5; // [letters] at tier 0
export const GYM_ANAGRAM_WORDS_PER_ROUND = 2; // [words]

export interface AnagramPuzzle {
  word: string;
  letters: readonly string[]; // the word's letters, scrambled
}

export interface GymAnagramRound {
  puzzles: readonly AnagramPuzzle[];
  durationS: number; // [s] the round clock
  difficulty: number; // [tier] 0-3
}

/**
 * Fisher-Yates with the given stream. A shuffle that lands on the word itself is rotated left by
 * one, which differs from the word unless every letter is the same (no bank word is).
 */
export function scrambleWord(word: string, rng: () => number): readonly string[] {
  const letters = Array.from(word);
  for (let i = letters.length - 1; i > 0; i -= 1) {
    const j = Math.floor(rng() * (i + 1));
    const swap = letters[i]!;
    letters[i] = letters[j]!;
    letters[j] = swap;
  }
  if (letters.join('') === word) letters.push(letters.shift()!);
  return letters;
}

/**
 * @param restS [s] the prescribed rest, RestTimer.durationS
 * @param priorWins [rounds] won earlier in this lifting day
 */
export function gymAnagramRound(context: RestGameContext, restS: number, priorWins: number): GymAnagramRound {
  const difficulty = restGameDifficulty(context, priorWins);
  const bank = GYM_WORDS[GYM_ANAGRAM_MIN_LENGTH + difficulty] ?? GYM_WORDS[GYM_ANAGRAM_MIN_LENGTH] ?? [];
  if (bank.length < GYM_ANAGRAM_WORDS_PER_ROUND) {
    throw new Error(`Gym Anagram needs ${String(GYM_ANAGRAM_WORDS_PER_ROUND)} words of one length`);
  }
  const rng = restGameRng('gymAnagram', context, difficulty);
  const first = Math.floor(rng() * bank.length);
  // A second index other than the first, uniform over the rest of the bank.
  const second = (first + 1 + Math.floor(rng() * (bank.length - 1))) % bank.length;
  const puzzles = [first, second].map((index) => {
    const word = bank[index] ?? bank[0]!;
    return { word, letters: scrambleWord(word, rng) };
  });
  return { puzzles, durationS: restRoundClockS(restS), difficulty };
}

/** Every word in the bank, for the curation tests. */
export function gymAnagramWords(): readonly string[] {
  return Object.values(GYM_WORDS).flat();
}

/** The source-data budget keeps the bank from creeping (< 2 KiB, tested). */
export function gymAnagramDataBytes(): number {
  return new TextEncoder().encode(JSON.stringify(GYM_WORDS)).byteLength; // [bytes]
}
```

```tsx
// src/ui/views/train/GymAnagramGame.tsx
//
// Gym Anagram (P6, R10): tap the scrambled tiles in order to spell the gym word; two words a
// round. A used tile is struck through and locked (a shape, not only a colour). It reads the rest
// timer and never writes it.
//
// Units: instants [ms] epoch UTC; the round clock [s].
import { useEffect, useState, type ReactElement } from 'react';
import { REST_GAME_FORMAT } from '../../../content/restGameFormat';
import { gymAnagramRound, type GymAnagramRound } from '../../../domain/fun/gymAnagram';
import { playRestGameCue } from '../../audio/restGameAudio';
import { RestGameFrame, type RestGameResult } from './RestGameFrame';
import { gameContext, type RestGameCopy, type RestGameProps } from './restGameProps';
import { useRoundClock } from './useRoundClock';
import '../../styles/restGames.css';

export const GYM_ANAGRAM_COPY = {
  titleKey: 'hero.restGameAnagram',
  ruleKey: 'advice.restGameAnagramRule',
} as const satisfies RestGameCopy;

export function GymAnagramGame(props: RestGameProps): ReactElement {
  const { timer, priorWins, soundsEnabled, t, overrides, onExit, onWin } = props;
  const context = gameContext(timer, 'GymAnagramGame');
  const [round] = useState<GymAnagramRound>(() => gymAnagramRound(context, timer.durationS, priorWins));
  const clock = useRoundClock(timer, round.durationS);
  const [solved, setSolved] = useState(0); // [words]
  const [picked, setPicked] = useState<readonly number[]>([]); // tile indices, in tap order
  const [wrong, setWrong] = useState(false);
  const [result, setResult] = useState<RestGameResult>(null);
  const puzzle = round.puzzles[solved] ?? round.puzzles[round.puzzles.length - 1] ?? { word: '', letters: [] };
  const canPlay = result === null && clock.remainingS > 0;

  useEffect(() => {
    if (result !== null || clock.remainingS > 0) return;
    setResult('timeUp');
    playRestGameCue('lose', soundsEnabled);
  }, [clock.remainingS, result, soundsEnabled]);

  const pick = (index: number): void => {
    if (!canPlay || picked.includes(index)) return;
    const next = [...picked, index];
    setWrong(false);
    if (next.length < puzzle.word.length) {
      setPicked(next);
      return;
    }
    const spelled = next.map((i) => puzzle.letters[i] ?? '').join('');
    if (spelled !== puzzle.word) {
      setPicked([]);
      setWrong(true);
      return;
    }
    const done = solved + 1; // [words]
    if (done >= round.puzzles.length) {
      setPicked(next);
      setResult('won');
      playRestGameCue('win', soundsEnabled);
      onWin();
      return;
    }
    playRestGameCue('submit', soundsEnabled);
    setSolved(done);
    setPicked([]);
  };

  const undo = (): void => {
    if (!canPlay) return;
    setPicked((value) => value.slice(0, -1));
  };

  const clear = (): void => {
    if (!canPlay) return;
    setPicked([]);
  };

  return (
    <RestGameFrame
      variant="rest-anagram"
      {...GYM_ANAGRAM_COPY}
      t={t}
      overrides={overrides}
      clock={clock}
      result={result}
      answer={puzzle.word}
      endNote={null}
      status={
        wrong
          ? t('status.restGameAnagramWrong')
          : REST_GAME_FORMAT.progress(solved, round.puzzles.length, overrides)
      }
      onExit={onExit}
    >
      <div className="rest-anagram-answer" role="group" aria-label={t('label.restGameAnagramAnswer')}>
        {Array.from({ length: puzzle.word.length }, (_, slot) => (
          <span className="rest-anagram-slot" key={slot}>
            {(puzzle.letters[picked[slot] ?? -1] ?? '').toUpperCase()}
          </span>
        ))}
      </div>

      <div className="rest-anagram-letters" role="group" aria-label={t('label.restGameAnagramLetters')}>
        {puzzle.letters.map((letter, index) => (
          <button
            type="button"
            // Keyed by word and position: the next word mounts fresh tiles.
            key={`${String(solved)}-${String(index)}`}
            className={picked.includes(index) ? 'rest-anagram-letter is-used' : 'rest-anagram-letter'}
            disabled={!canPlay || picked.includes(index)}
            onClick={() => {
              pick(index);
            }}
          >
            {letter.toUpperCase()}
          </button>
        ))}
      </div>

      <div className="rest-anagram-tools">
        <button type="button" className="rest-anagram-undo" disabled={!canPlay || picked.length === 0} onClick={undo}>
          {t('button.restGameAnagramUndo')}
        </button>
        <button type="button" className="rest-anagram-clear" disabled={!canPlay || picked.length === 0} onClick={clear}>
          {t('button.restGameAnagramClear')}
        </button>
      </div>
    </RestGameFrame>
  );
}
```

```ts
// src/ui/views/train/useSheetDismiss.ts
//
// Back and Escape close the game sheet (P6, plan D5). Opening pushes one history entry marked
// MARK; a popstate that lands on an unmarked entry is Back and closes the sheet; closing any other
// way steps back over the sheet's own entry, so the history stays as it was. A popstate that lands
// on a marked entry is ignored: under React StrictMode the effect runs twice and the first
// cleanup's step back arrives after the second push. Escape is left to a modal dialog open above
// the sheet (form cues, video).
//
// P4 (R6: one history entry per overlay) replaces this hook with its overlay stack.
import { useEffect, useRef } from 'react';

const MARK = 'ftiRestGameSheet';

function isSheetEntry(state: unknown): boolean {
  return typeof state === 'object' && state !== null && (state as Record<string, unknown>)[MARK] === true;
}

export function useSheetDismiss(onDismiss: () => void): void {
  // The latest handler, read at event time, so the history entry is pushed exactly once.
  const dismissRef = useRef(onDismiss);
  useEffect(() => {
    dismissRef.current = onDismiss;
  });

  useEffect(() => {
    window.history.pushState({ [MARK]: true }, '');
    let popped = false;
    const onPop = (event: PopStateEvent): void => {
      if (isSheetEntry(event.state)) return;
      popped = true;
      dismissRef.current();
    };
    const onKey = (event: KeyboardEvent): void => {
      if (event.key !== 'Escape') return;
      if (document.querySelector('[aria-modal="true"]') !== null) return;
      dismissRef.current();
    };
    window.addEventListener('popstate', onPop);
    window.addEventListener('keydown', onKey);
    return () => {
      window.removeEventListener('popstate', onPop);
      window.removeEventListener('keydown', onKey);
      if (!popped && isSheetEntry(window.history.state)) window.history.back();
    };
  }, []);
}
```

```tsx
// The rest-game host (P6, R10; audit C14). A NON-MODAL bottom sheet fixed over Train: the page

import { useCallback, useEffect, useMemo, useRef, useState, type ReactElement } from 'react';
import type { CopyKey } from '../../../content/copy';
import { REST_GAME_FAMILIES, seededFamily, type RestGameFamily } from '../../../domain/fun/restGames';

import { useSheetDismiss } from './useSheetDismiss';
import '../../styles/restGames.css';

export interface RestGameSheetProps {
  /** Read only: startedAt and endsAt [ms] epoch UTC, durationS [s]. */
  timer: RestTimer;
  priorWins: number; // [rounds] won earlier in this lifting day
  soundsEnabled: boolean; // ui.sounds
  units: UnitSystem; // the active profile's units
  t: (key: CopyKey) => string;
  overrides: Readonly<Partial<Record<CopyKey, string>>>;
  /** played: true once a round was started, so the rest's one offer is spent. */
  onClose: (played: boolean) => void;
  onWin: () => void;
}

export const REST_SHEET_BODY_CLASS = { open: 'rest-sheet-open', minimised: 'rest-sheet-min' } as const;

interface PickerOpening {
  order: readonly RestGameFamily[];
  tag: RestGamePickerTag;
}

export function RestGameSheet(props: RestGameSheetProps): ReactElement {
  const { timer, priorWins, soundsEnabled, units, t, overrides, onClose, onWin } = props;
  const context = gameContext(timer, 'RestGameSheet');
  // Read once when the sheet opens, so the list never reorders under the user's thumb.

    const remembered = rememberedRestGameChoice(context.sessionId);
    const first = remembered ?? seededFamily(context);
    const tag: RestGamePickerTag = remembered === null ? 'suggested' : 'lastPlayed';

  const [minimised, setMinimised] = useState(false);

  const close = useCallback((): void => {
    onClose(family !== null);

    const name = minimised ? REST_SHEET_BODY_CLASS.minimised : REST_SHEET_BODY_CLASS.open;
    document.body.classList.add(name);
    return () => {
      document.body.classList.remove(name);
    };

  // (RestWordGame accepts keys whose target is inside `.rest-sheet`); it goes back on close.
  useEffect(() => {
    const opener = document.activeElement instanceof HTMLElement ? document.activeElement : null;
    sheetRef.current?.focus();
    return () => {
      if (opener?.isConnected === true) opener.focus();
    };
  }, []);

  const host = useMemo<RestGameHost>(
    () => ({
      units,
      hidden: minimised,
      onHide: () => {
        setMinimised(true);
      },
    }),

  );

      ref={sheetRef}
      tabIndex={-1}
      role="dialog"
      aria-modal="false"

        <div className="rest-sheet-bar">
          <span className="rest-sheet-bar-name">{t(entry.titleKey)}</span>
          <button
            type="button"
            className="rest-sheet-show"
            onClick={() => {
              setMinimised(false);
            }}
          >
            {t('button.restGameShow')}
          </button>
        </div>
      )}
      {/* Hidden, not unmounted: the round, its clock and its board survive Hide. */}
      <div className="rest-sheet-body" hidden={minimised}>
        {entry === null ? (
          <RestGamePicker
            families={opening.order}
            tag={opening.tag}
            t={t}
```

```ts
  sheetTop: number; // [px] from the viewport top

async function openRestWord(page: Page): Promise<void> {
  await page.getByRole('button', { name: 'Play a Game' }).click();
  await page.getByRole('button', { name: 'Rest Word' }).click();
  await expect(page.getByRole('heading', { name: 'Rest Word' })).toBeVisible();

/** Scrolls the next unlogged row to just under the sticky top bar, then measures. */
async function measure(page: Page): Promise<Layout> {
  const layout = await page.evaluate((): Layout | null => {
    const keys = [...document.querySelectorAll('.rest-word-key')].map((key) => key.getBoundingClientRect());
    const row = document.querySelector('.set-row:not(.done)');
    const bar = document.querySelector('.topbar');
    const sheet = document.querySelector('.rest-sheet');
    if (row === null || bar === null || sheet === null || keys.length === 0) return null;
    window.scrollBy(0, row.getBoundingClientRect().top - bar.getBoundingClientRect().bottom);
    const r = row.getBoundingClientRect();
    const s = sheet.getBoundingClientRect();
    const buttons = [...row.querySelectorAll('button')];
    const log = buttons[buttons.length - 1];
    return {
      keyMinW: Math.min(...keys.map((k) => k.width)),
      keyMinH: Math.min(...keys.map((k) => k.height)),
      overflowX: document.documentElement.scrollWidth > window.innerWidth,
      topbarH: bar.getBoundingClientRect().height,
      rowH: r.height,
      logBottom: log === undefined ? null : log.getBoundingClientRect().bottom,
      sheetTop: s.top,
      sheetH: s.height,
      sheetInnerScroll: sheet.scrollHeight - sheet.clientHeight,
    };
  });
  if (layout === null) throw new Error('the sheet, the top bar or the next set row is missing');
  return layout;
}
```
