## 6. Four traps that cost real time, and will again

- **Assume every agent worktree branches from a STALE commit.** It happened to nearly every agent
  dispatched on 2026-09-09 and 2026-09-10, including two dispatched in the same message. Put
  `git merge main` in the agent's own prompt as step 1 and make it report both commits.
- **The wizard test fixtures navigate by COUNTING `next()` presses**, not by naming steps. Folding
  one step out of the wizard cost seven separate navigation routes across two files, and each
  failure surfaced lines later as a missing control rather than as a navigation error.
- **A copy key may be claimed by exactly ONE part** in `alpha-parts.mjs`. A collision always means
  a new key, never a second claim.
- **This machine runs MATLAB in another session.** A full `vitest run` gets killed under that
  memory pressure. Run with `--maxWorkers=1` and by directory; a `Test timed out` is not an
  assertion failure and must not be reported as one. Check for `AssertionError` before calling
  anything a test failure.
