## 4. Enabling reminders (the Worker)

`docs/RUNBOOK-reminders.md` is the whole procedure. Every Wrangler command runs from `worker/`,
because Wrangler is installed only in that package.

**Step 1, the account (section 1).** Sign up at `https://dash.cloudflare.com/sign-up`. The Workers
Free plan needs no payment method.

**Step 2, authenticate Wrangler (section 2).**

```bash
cd worker
npx wrangler --version
npx wrangler login
npx wrangler whoami
```

**Step 3, the KV namespace (section 3).** Paste the printed id over the placeholder in
`worker/wrangler.toml`.

```bash
npx wrangler kv namespace create REMINDERS
grep -n -A2 kv_namespaces wrangler.toml
```

**Step 4, the VAPID key pair (section 4).** Generate it once. Regenerating it invalidates every
existing subscription, and every device has to enable reminders again.

```bash
npx @pushforge/builder vapid
```

**Step 5, the private key as a secret (section 5).** Paste the whole JWK JSON object on one line and
do not reformat it.

```bash
npx wrangler secret put VAPID_PRIVATE_JWK
```

**Step 6, the three plain variables (section 6).** Set `VAPID_PUBLIC_KEY`, `ADMIN_CONTACT` and
`ALLOWED_ORIGIN` in `worker/wrangler.toml`. `ALLOWED_ORIGIN` is `https://vkotzamanis.github.io`,
with no trailing slash and no path, and one wrong character turns every browser call into a 403.

```bash
grep -n REPLACE wrangler.toml
```

**Step 7, deploy (section 7).** Run it from the repository root. Write the printed Worker URL down.

```bash
cd ..
npm --prefix worker run deploy
```

**Step 8, the health check (section 8).**

```bash
curl -s https://fti-reminders.<subdomain>.workers.dev/v1/health
npm --prefix worker run tail
```

Expect `{"ok":true,"vapidPublicKey":"<the public key from step 4>"}`, then a tick line reading
`tick devices=0 sent=0 failed=0 removed=0 writes=0`. Stop the tail with Ctrl-C.

**Step 9, the two repository variables (section 9).** Open Settings, then Secrets and variables, then
Actions, then the Variables tab. Both values are public by design.

| Variable | Value |
| --- | --- |
| `VITE_REMINDER_API` | the Worker origin from step 7, with no trailing slash |
| `VITE_VAPID_PUBLIC_KEY` | the public key from step 4 |

**Step 10, redeploy Pages and verify the policy (section 10).** A build started before step 9 carries
no variables, so re-run the Deploy workflow.

```bash
curl -s https://vkotzamanis.github.io/FixThisInjustice/ | grep -o "connect-src [^;]*"
```

Expect `connect-src 'self' https://fti-reminders.<subdomain>.workers.dev`. A bare
`connect-src 'self'` means the build ran without `VITE_REMINDER_API`.

Then enable reminders on the phone (section 12).

| Platform | Requirement |
| --- | --- |
| iPhone and iPad | iOS 18.4 or later, installed to the Home Screen |
| Android Chrome | push works in a tab, so installing is optional |

The install is not optional on iOS. Safari delivers Web Push only to a web app installed on the Home
Screen. This app sets its floor higher because Screen Wake Lock stayed broken inside an installed app
until that release. Section 11 states the free plan budget, and subrequests bind first at roughly
twenty devices. Section 14 is the troubleshooting table, and section 15 rolls the Worker back with
`npx wrangler rollback`.

## 7. How the work was done, and the rules that bit

Subagents drove every plan. One implementer took a plan task, an independent reviewer checked the
result against the plan, and a fix agent closed what the review found. Every claim carried the command
that proved it, and a claim without a command did not ship.

Several agents shared one working tree, which forced three rules. Commit with an explicit pathspec,
never `git add -A`, because a bare commit sweeps in another agent's staged files. Never use
`git commit --amend`. Build a shared file's blob from `HEAD` immediately before committing it, because
another agent may hold edits to the same file.

Decisions live inline in the plans, tagged with a one-line header of the form
`<!-- decision: <slug> | status: adopted -->`. Answer "why did we choose X" by traversing the graph
rather than by re-reading documents:

```bash
graphify query "why did we choose X"
```

Copy obeys a contract. `docs/design/2026-09-01-copy-contract.md` states thirteen rules, and
`src/content/copy.test.ts` enforces most of them mechanically. The mechanical checks cover word caps
per family, em dashes, emoji, exclamation marks, unit-symbol parity across skins, and a call-site
gate that finds every key. Two rules stay human judgements, R7 and R11, and
`src/content/copy.test.ts` says so at line 965.

A skin changes words, icons, tokens and optional sounds. It never changes a number, a unit symbol, a
slot or what a control does. A skin also never jokes on a control whose misreading costs data. The
wipe, the import, the legacy delete, the export and the reminder states therefore carry no rows.
